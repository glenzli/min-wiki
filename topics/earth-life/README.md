# 古生命与生态馆 / Ancient life and ecosystems

核心问题不是“哪个时代出现了更高级的生物”，而是“哪些生物一起生活、怎样联系，我们凭什么这样复原”。本馆只拥有 `topics/earth-life/**` 的内容、模型和演示；独立入口和地球博物馆通过 `mountStudy(host, context)` 复用同一实例合同。

## 四个工作台

1. **群落现场**：七组时空固定的案例，微生物岸带、白海埃迪卡拉、伯吉斯页岩、石炭纪煤湿地、二叠纪末海洋、白垩纪末陆地、晚更新世猛犸草原。证据镜头改变哪些对象和关系被强调，始终保留对象 ID 与每个群落自己的选择。每个节点有可核对记录、推断及不能确定的部分。生态关系与谱系关系明确分开。
2. **化石筛选实验**：相邻海陆来源的十二份固定教学残体经过沉积地点、保存过程、采样三道筛选。主动播放一段约九秒的有限讲解，十二个固定身份的图形沿各自行走路径经过四站；没进入此地的材料停在来源，失去可辨形态的材料留下虚影，未采到的保存材料停在保留处。可暂停、复位、逐站观察或拖动进度，也可直接选终点静态结果。地点和保存不同会产生不同记录；扩大采样只含更多同地点保存材料。规则与动画时间都是教学安排，不输出保存概率、灭绝比例、真实丰度、搬运距离、腐解速率或地质时长。
3. **植物形态工坊**：原创连续网格呈现树状石松类叶座及小叶痕、节类节点/节间及轮生枝、种子蕨复叶及分叉脉纹。整体/局部模式是观察范围，不是演化或生长进度。程序复原不是扫描，不提供实测标尺。
4. **瓦普塔虫3D**：只深化一个伯吉斯Walcott背景的完整古动物，不扩物种菜单。依据2018重描述保留十三对附肢、中部融合节、六个无足腹节与成对三假节尾枝。代表中线体长50毫米，不含触角；一单位对应10毫米。完整身体、部位高亮、背/腹/侧面共用一个资产，真实CC BY化石图版与逐部位依据并列。十秒有限片肢动作可暂停、回拖、复位，与静止形态对照；节律、配色、体积、摆放和细毛加粗有明确补全限定。没有捕食、海底爬行、水动力、呼吸量或真游速输出。

## URL 与生命周期

完整状态有十二键：`view`, `community`, `lens`, `focus`, `phase`, `deposit`, `burial`, `sample`, `plant`, `detail`, `fossilProgress`, `animal`。`focus` 只接受七个已知群落内真实存在的节点；JSON 和所有字段有严格范围。`fossilProgress` 只接受 0–100 的整数，默认 0 且暂停；四站为 0、33、67、100，播放状态不写入 URL。`animal`只接受最多1024字符的严格JSON，含部位、镜头、证据强调、静止/片肢动作及0–100进度，未知字段丢弃；不接受自动播放或自定附肢数。序列化为完整快照，不依赖增量合并。`phase` 只作用于支持前后景的微生物、二叠纪末与白垩纪末案例。旧十一键地址保持原意。

3D 按需动态导入，generation 与 disposed 防止过期结果挂载。离开植物工作台即销毁 GPU 实例。展示共享 `../earth/threeStage.ts`，没有自己的 renderer 或持续 RAF；可见性与按需重绘由共享 stage 负责，植物切换释放旧几何/材质。导入失败、WebGL 丢失保留说明与二维图，重试整页 reload 保留 URL。所有 DOM 查询限制在本馆根节点内；没有自动声音或自动推进。

动物工作台和动物场景分别延迟导入；植物与动物切换先销毁旧场景，最多一个活动WebGL。`burgessGeometry.ts`拥有原创建模与骨架，`burgess/scene3d.ts`拥有光照、观察地面与同单位尺，`burgess/study.ts`拥有证据UI和共享有限播放器。销毁资产会释放骨架纹理，再由stage释放剩余场景资源。播放不新建网格、纹理或画布，证据高亮不改变器官身份或动作进度。实际图版仅在动物工作台需要时载入。

二维筛选播放使用共享 `../earth/finitePlayback.ts`，不另写时钟。它只在主动播放的一段有限时间内请求帧；暂停、完成、离屏、文档隐藏、切工作台、外部 `pause()` 与销毁都会停止。减少动态效果偏好下仅依次显示四站，也保留手动控件。每帧更新既有十二个 SVG 图形的变换、透明度与教学破损符号，不重建 SVG。每帧发出完整内存状态，URL 持久化限频由博物馆协调器负责。播放时 live announcement 关闭，暂停/结束才播报当前阶段与计数。
