# 古生命与生态馆 / Ancient life and ecosystems

核心问题不是“哪个时代出现了更高级的生物”，而是“哪些生物一起生活、怎样联系，我们凭什么这样复原”。本馆只拥有 `topics/earth-life/**` 的内容、模型和演示；独立入口和地球博物馆通过 `mountStudy(host, context)` 复用同一实例合同。

## 三个工作台

1. **群落现场**：七组时空固定的案例，微生物岸带、白海埃迪卡拉、伯吉斯页岩、石炭纪煤湿地、二叠纪末海洋、白垩纪末陆地、晚更新世猛犸草原。证据镜头改变哪些对象和关系被强调，始终保留对象 ID 与每个群落自己的选择。每个节点有可核对记录、推断及不能确定的部分。生态关系与谱系关系明确分开。
2. **化石筛选实验**：相邻海陆来源的十二份固定教学残体经过沉积地点、保存过程、采样三道筛选。主动播放一段约九秒的有限讲解，十二个固定身份的图形沿各自行走路径经过四站；没进入此地的材料停在来源，失去可辨形态的材料留下虚影，未采到的保存材料停在保留处。可暂停、复位、逐站观察或拖动进度，也可直接选终点静态结果。地点和保存不同会产生不同记录；扩大采样只含更多同地点保存材料。规则与动画时间都是教学安排，不输出保存概率、灭绝比例、真实丰度、搬运距离、腐解速率或地质时长。
3. **植物形态工坊**：原创连续网格呈现树状石松类叶座及小叶痕、节类节点/节间及轮生枝、种子蕨复叶及分叉脉纹。整体/局部模式是观察范围，不是演化或生长进度。程序复原不是扫描，不提供实测标尺。

## 科学与素材边界

所有 SVG 路径、网格、叶脉和表面颜色在本馆源码中原创生成，未复制博物馆照片、展柜、扫描模型、纹理或其他展馆资产。来源用于约束形态与解释，不构成外部素材的再许可。未知色泽、姿态与间距均为展示补全。

| 资产 | 时空与形态约束 | 推断/补全部分 |
| --- | --- | --- |
| 微生物岸带 SVG | 约 27 亿年前的代表浅海，另对照约 24–21 亿年前氧化环境；层状构造、硫同位素等 | 功能组不等于物种鉴定；不把叠层构造独自视作产氧证据。气泡编码产氧，不是古空气测量。 |
| 埃迪卡拉 SVG | 白海约 558 Ma；Dickinsonia、Kimberella 压痕、席和相关遗迹 | 不是现代水母/蜗牛。摄食方式分层标记，不擅补眼睛或牙齿。 |
| 伯吉斯 SVG | 加拿大约 508 Ma；Olenoides 和 Anomalocaris 身体结构、海绵等功能组 | 群落组合非一块化石板；不将奇虾默认画成成年三叶虫的碎壳捕食者。不是寒武纪起点。 |
| 煤湿地 SVG/3D | 欧美古赤道约 310 Ma 形态组；叶座/叶痕、节点/节间、种子蕨复叶与叶脉 | 不是某件完整标本；Calamites 髓腔铸型不冒充外表皮。没有把约 285 Ma 的 NPS 种子蕨标本搬到此景。 |
| 二叠纪末 SVG | 约 252 Ma 前后浅海功能组，古生代珊瑚和三叶虫分支终止 | 前后幸存的是大类群中一些支系，非同一个体或全部原物种；淡化非测得比例。 |
| 白垩纪末 SVG | 约 66 Ma 与早古新世代表组合 | 鸟在恐龙内部，部分鸟支延续；哺乳类早已存在且有损失。没有一键全球同步恢复。 |

## URL 与生命周期

完整状态有十一键：`view`, `community`, `lens`, `focus`, `phase`, `deposit`, `burial`, `sample`, `plant`, `detail`, `fossilProgress`。`focus` 只接受七个已知群落内真实存在的节点；JSON 和所有字段有严格范围。`fossilProgress` 只接受 0–100 的整数，默认 0 且暂停；四站为 0、33、67、100，播放状态不写入 URL。序列化为完整快照，不依赖增量合并。`phase` 只作用于支持前后景的微生物、二叠纪末与白垩纪末案例。

3D 按需动态导入，generation 与 disposed 防止过期结果挂载。离开植物工作台即销毁 GPU 实例。展示共享 `../earth/threeStage.ts`，没有自己的 renderer 或持续 RAF；可见性与按需重绘由共享 stage 负责，植物切换释放旧几何/材质。导入失败、WebGL 丢失保留说明与二维图，重试整页 reload 保留 URL。所有 DOM 查询限制在本馆根节点内；没有自动声音或自动推进。

二维筛选播放使用共享 `../earth/finitePlayback.ts`，不另写时钟。它只在主动播放的一段有限时间内请求帧；暂停、完成、离屏、文档隐藏、切工作台、外部 `pause()` 与销毁都会停止。减少动态效果偏好下仅依次显示四站，也保留手动控件。每帧更新既有十二个 SVG 图形的变换、透明度与教学破损符号，不重建 SVG。每帧发出完整内存状态，URL 持久化限频由博物馆协调器负责。播放时 live announcement 关闭，暂停/结束才播报当前阶段与计数。

## 验证

```sh
node --import tsx --test topics/earth-life/tests/*.test.mjs
npm run typecheck
```

12 项测试覆盖范围枚举/畸形状态、身份回访、灭绝前后断连及幸存支、全组合化石筛选、嵌套采样、有限顺序回拖与终点等价、有限网格与稳定重建。手机最大 22,046 三角形，桌面最大 52,766；这是本地网格实测预算，不是生物尺寸数据。真实 Reader 的双语手机/桌面、模块故障与跨馆状态检查由本轮整合验收补充记录。
