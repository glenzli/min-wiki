# AI 是什么？ / What is AI?

The core question is what AI tools are and how children can use judgment around them. This topic deliberately introduces concepts and everyday roles rather than model internals or a training lesson.

- Three editable **prewritten** example displays: ideas, image generation, recognition. The clearer-request control switches authored pairs, not an inference engine.
- Person/program/AI/robot comparisons explain overlap: AI is implemented with programs; robot embodiment is a separate property.
- Five situational task cards choose a useful first action. The guidance is specific to the supplied context, not an absolute capability or permission taxonomy.
- Three evidence activities separate correct (directly countable), overbroad (material comparison) and unverified (missing real notice) answers. Asking twice is not independent verification.

`model.ts` owns finite selection and answer history. Reading depth changes only disclosure; it does not reset the activities. There is no animation loop, free input, account, model API, network submission, or personal-data persistence. Navigation/theme/language preferences remain the existing platform behavior. Image and recognition examples are editorial illustrations, not real inference.
