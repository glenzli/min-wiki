# Storm illustration sources · 2026-10-19

These are AI-generated educational illustrations, not photographs or observed weather. Generated with the built-in imagegen tool. No external reference images were supplied. Original alpha PNGs are retained alongside compact WebP delivery copies; no generated image contains the model's lightning geometry, charges, sound fronts or measurement labels.

| Source | Delivery | Role |
| --- | --- | --- |
| storm-cloud-v1.png | storm-cloud-v1.webp | Nonmetric storm-cloud material and silhouette |
| observer-house-v1.png | observer-house-v1.webp | Enlarged indoor architectural reference |
| storm-terrain-v1.png | storm-terrain-v1.webp | Illustrative rural terrain, no real location |

The cloud and landscape are fixed-view artwork; their light masks sample the connected return stroke. The house's left ground-floor window is anchored to the observer distance projection. Architecture, terrain and cloud sizes are independently illustrative; none gives a calibrated physical length. See ../README.md for the causal model and ../VALIDATION.md for actual browser evidence. Rebuild delivery copies with `npm run optimize:images` and verify with `npm run check:images`.

Cloud fully contained with generous transparent margins, anvil spanning nearly full width; taller main updraft body slightly left of center, its irregular dark lower base at approximately 80 percent image height, a shallower airy anvil extending right. Side view from a distant low ground observer. Whole cloud visible, no cropping.
Style: exceptionally refined natural history illustration with photo-informed volume and subtle painterly material detail, realistic large-scale cloud structure, coherent soft overcast light from upper left, no hard outlines. Cool neutral slate and silver gray, restrained blue undertones; dark parts still retain detail. Light top, dense dark underside.

Constraints: only one cohesive storm cloud, no lightning, no rain strokes, no landscape, no sun, no decorative glow, no symbols, no typography, no watermark, no checkerboard painted into image. No isolated cotton balls, no coarse speckles. This is schematic educational artwork, not an observed weather photograph.
