# Planet texture attribution

Planet maps, Earth cloud map, Moon map and Saturn ring strip: **Solar System Scope / INOVE**, https://www.solarsystemscope.com/textures/ . Distributed under **Creative Commons Attribution 4.0 International**, https://creativecommons.org/licenses/by/4.0/ . Downloaded 2026-09-08.

Files are original 2k assets (`2k_*.jpg`, `2k_saturn_ring_alpha.png`). No image edits. The application maps them onto spheres/rings, adds lighting, and combines Earth's day map with the cloud map. Venus uses the atmosphere map rather than exposing the surface beneath its clouds.

The source uses NASA imagery and elevation data with color adjustments and fills some unmapped areas with plausible terrain. These are educational visual maps, not live spacecraft images. Cloud patterns and surface seasons are static.

The topic cover `../cover-v2.jpg` was generated with OpenAI ImageGen for this project and encoded as JPEG. It is an illustration; arrangement and distances are schematic.
