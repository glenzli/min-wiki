# 太阳系八大行星运转与大小比较

四种探索情景：公转全景、等比例排排队、类地内行星、四大巨行星。每种提供五步儿童讲解与对应学术说明。进入页面时暂停；定位时间或切换情景也会暂停。

公转使用数据表中的半长轴、偏心率、倾角与周期，数值求解开普勒方程。每条椭圆分别缩放以压缩轨道间距，天体另外放大。初始相位和轨道朝向是示意，不是日历星历；不计算多体摄动。时间轴一轮是十二个模拟年。

排排队以同一个直径尺度绘制太阳和八大行星，采用正交相机；“全部天体”完整显示太阳，“只看行星”放大行星队列。补光用于辨认球体轮廓，间隔只用于排版。月球和小行星带为示意，不能从画面测量真实距离。

行星卡片显示数据直径、相对地球直径、公转周期、自转周期；学术读数 a³/T² 根据所选行星计算，单位为 AU³/年²。球体使用 Solar System Scope 的 2k 等距柱状贴图；地球叠加云图，土星环使用径向透明贴图。纹理来源、许可和处理见 assets/ATTRIBUTION.md。

在仓库根目录运行 `npm test`、`npm run build`；开发入口为 `/topics/solar-system/`。测试覆盖椭圆焦点、周期复现、等面积速度、近远日点速度及数据和故事阶段。

数据参考：[NASA Planetary Fact Sheet](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)；[NASA 开普勒定律](https://science.nasa.gov/solar-system/orbits-and-keplers-laws/)。
