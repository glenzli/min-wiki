# 蝌蚪怎样变成青蛙？

展示有自由生活蝌蚪阶段的典型蛙类。实际发育连续，前后腿、肺和尾的变化部分重叠；不同种类与温度下时间差异很大，因此不标统一天数。部分蛙类不经历自由游泳的蝌蚪阶段。图中动物放大、简化，成蛙还会通过皮肤参与气体交换。
