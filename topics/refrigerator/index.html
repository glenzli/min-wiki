03 / 工作时，冷媒怎样走

金色圆框追踪管内的一小份冷媒；小圆点是放大符号。这里单独解释机器工作时的一圈，不表示压缩机一直开着。

热量的去向

食物 → 箱内 → 房间

食物把热传给周围空气和较冷的内壁。冷媒在管内吸热，再把热带到箱外。它不会流进食物，也不是喷出来的冷气。

门与保温层

少让外面的热跑进来

保温层和门封减慢热量进入。开门时，较暖的空气进来，冷空气流出去；冰箱又要多搬一些热。

电能也去了哪里

房间收到的热更多

散到房间的热，包含从箱内搬出的热，也包含机器消耗的电能。所以把门一直敞着，不能靠冰箱给整个房间降温。

深入看：热量收支、相变与温控

工作循环中，蒸发器吸热 Qc，压缩机接受功 W，冷凝器向室内放热 Qh。忽略一个完整循环后的内部储能变化，Qh = Qc + W。制冷性能系数 COP = Qc/W 可以大于 1，因为衡量的是搬运的热量与输入功之比，并不是凭空产生能量。

低压冷媒在蒸发器中吸热、部分或全部汽化。压缩机吸入蒸气并提高压力与温度；冷凝器先冷却较热蒸气，再把它凝结成液体。液体经毛细管等节流装置降压，部分闪蒸，低温混合物返回蒸发器。节流不是压缩机的反向发电过程。

本页用两个热容分别表示箱内空气连同内胆，以及食物。门的开合改变等效漏热系数；食物与空气之间也有温差驱动的传热。温控器以两个不同阈值启停，避免在一个阈值附近反复抖动。画面省略湿气凝结、除霜、风扇细节、不同食品形状和真实制冷剂性质。

这里只画一个冷藏空间。真实冰箱可能把蒸发器、冷凝器藏在内壁或侧壁，可能有冷冻室、风道和多回路；这幅图不用于拆机或维修。
