# 一滴水的旅行

从地面的水，到云里的小水滴，再回到河流和大海。

面向 4–6 岁，由儿童与成人共同操作。`index.html` 与专题内的 TypeScript、SVG、翻译和样式构成独立页面；共用平台只负责导航、语言及阅读主题。

页面提供原生按钮、选择框及可用方向键操作的进度/条件控件。无自动音频或后台播放。儿童讲解随当前条件变化；折叠的家长说明保留科学范围、教学简化和一手来源。

## 连续观察

“慢慢走完一圈”按有限的 18 秒教学时间推进，可暂停、用方向键拖动进度、选阶段或重新观察。页面隐藏时停止；减少动态效果偏好使用静态终态。条件切换连续改变同一组蒸发符号的可见程度，不预测雨量。

`model.ts` 统一拥有代表路径和每滴雨的出生、下落、山坡接触位置。路径亮线和圆框共用坐标，河口至海面连续相接；到达山坡的雨滴留下湿痕，不重新回到云底。闭合图形仅服务本次观察，不表示水必然返回同一位置。
