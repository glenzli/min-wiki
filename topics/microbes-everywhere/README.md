# 微生物为什么几乎无处不在？

切换土壤、池水、皮肤、空气；打开示意放大镜，结合静态图文区分迁移、存活与繁殖。事件驱动 SVG，没有自动计时器或持续资源。

微生物是宽泛术语，细菌属于细胞生物；病毒不属于细胞，仍属于微生物学研究范围。四种场景的颜色、数量、形状不代表测量，普通放大镜不足以观察大多数单个微生物。无培养、检测或诊断功能。
