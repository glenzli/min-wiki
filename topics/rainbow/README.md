# 彩虹从哪里来？

融合写实环境和增强光路的互动光学示意，包含三棱镜、雨滴、双彩虹与天空四个情景，配有中英双语和两种讲解深度。

- 默认暂停。未照亮的光路不预先显示；播放会逐段照亮连续光带，20 秒结束后停住。选步骤、拖动进度条和重播都会暂停，便于逐段观察。
- 点选颜色突出对应光线，详情显示在画布下方；关闭详情恢复完整光谱。
- 天空情景可调太阳高度，并比较平坦地面与无遮挡全圆视野。
- 阅读界面默认白色，仍尊重全站手动深色偏好；实验画布采用冷灰环境光、玻璃反光和柔和光束；天空及双虹叠加雨后地景，保持控制与标注可读。

## 模型边界

`data/rainbowData.ts` 提供代表色折射率、主副虹角度计算和球形雨滴光路。光路边界点、反射与出射方向由同一模型产生，详情角度也由该模型计算。测试核对球面交点、内反射定律、出射斯涅尔定律和角度一致性。

`physics/rainbowSimulation.ts` 使用 Canvas 2D 呈现剖面光路和天空方向示意，无需 WebGL。棱镜光路和汇聚透镜是教学示意，色散间距及光带宽度经过放大，不用于设计实验装置。棱镜光谱使用 49 条连续波长光线，雨滴使用七条代表光线，每条光线共享折射与反射处的连接点，避免分段色块接缝和逐色块模糊。七个标签可突出代表色；动画时间不代表真实光速。雨滴各界面的互补反射或透射支路以半透明虚线展示，遵循反射和折射方向；虚线亮度仅用于区分路线，不代表能量比例。

天空视图展示角半径，地平线位置采用简化角度图；地面模式假定平坦、不透明的地面，全圆模式假定各方向均有合适雨雾且无视线遮挡。未模拟波动光学、偏振、宝光、副轮或真实散射亮度。暗带仅表示主副虹光路缺少贡献，不能解释成完全无光。

`main.ts` 管理控制、播放与讲解，`story.ts` 保存四组五步内容，`locales/en.json` 保存专题英文翻译。

## 验证

在仓库根目录运行 `npm run check`。从生产预览检查四个情景的步骤、颜色、汇聚开关、太阳高度、全圆视野、语言切换与手机布局。

## 视觉素材

网页加载保留原尺寸的 `assets/rain-afterglow.webp`；原始 PNG 继续保留用于编辑。运行 `npm run optimize:images` 可重新生成派生图片，构建前会核对来源与文件摘要。

`assets/rain-afterglow.png` 由内置 imagegen 生成，作为环境插画，不是观测照片。提示词：16:9 写实雨后平坦草甸，地平线约在画面 55% 高度；灰蓝云层、远方雨幕、湿草与浅水，光从观察者身后照来；无彩虹、太阳、文字、人物和建筑。彩虹、光路、地平线遮挡仍由程序绘制。环境图的天空与地面按固定地平线映射，太阳升高时反太阳点和彩虹向下移动；全圆模式仅使用天空部分，属于方向示意而非真实相机投影。雨滴内倒置环境仅表达折射质感，未做环境光线追踪。
