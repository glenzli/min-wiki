# Ice and climate gallery

This independently routed gallery is also mounted inside the Earth museum through the same `StudyContext`/`StudyInstance` interface. It owns selected glacial chronology, reflection and water-equivalent budgets, original diagrams and a hypothetical 3D glacier valley.

The default `journey` is a single multiscale workbench, with retained `global → region → evidence` scope at fixed hypothetical region A (45°N, reference meridian 35°). Legacy explicit `history`, `reflection` and `glacier` links remain valid. Global cover uses a reference-sphere area relation with a zero-mean irregular longitude perturbation; the shader and region predicate share it. The meridian-specific edge readout is not a global average latitude. Original land texture is anchored to a hypothetical shoreline at A, without modern or ancient basemap data.

The coast section distinguishes seawater freezing from upland snowfall, compaction and recrystallization. Global cover links to the coast's sea-ice context and the existing uniform 100-portion reflection budget. It never advances the independent glacier budget. P1 sea ice, P2 upland snow, P3 sediment, P4 bedrock scratches and P5 modern ice-core methods are explicitly different teaching samples, not measured material generated by the globe or surviving Cryogenian ice. Static bilingual entries give the same mechanisms, conditions and limitations.

## Questions, observations and boundaries

- **Historical evidence:** nine selected records/backgrounds range from Huronian glaciations through the Sturtian/Marinoan, late Ordovician, late Paleozoic, Antarctic ice sheets, Quaternary cycles, the recent glacial maximum and Holocene. Ages are stored in Ma. Each time window is separately linear. Narrower-than-pixel intervals use explicitly qualified location dots, not inflated durations. These categories overlap and are not an exhaustive list of regional glaciations.
- **Surface reflection:** the input is always 100 teaching energy portions. Ice-area and snow reflectivity change reflected/absorbed amounts under the same fixed input. Water reflectivity 0.1 and snow/ice reflectivity 0.5–0.9 are chosen surface examples; this is neither cloud-inclusive planetary albedo nor a surface-temperature calculation. Positive feedback is explained in both directions and is not a prediction of runaway freezing.
- **Ice mass:** the same hypothetical glacier begins with 60 water-equivalent units. Each round adds accumulation and removes at most the available mass. Manual steps, reversible scrub and optional finite playback share this budget. `glacierPlayback.ts` interpolates adjacent existing round outcomes for smooth observation, including added/lost mass and the history cursor; integer endpoints exactly match `glacierBudget`. Display seconds are compressed presentation time and rounds are not years. Shape is not a calibrated volume, flow or terminus-position model.
- **Land and floating ice:** equal water-equivalent masses illustrate the main contrast between water newly added to the ocean and mass already displacing water. Floating melt's direct effect is approximated as zero, with salt/density corrections and indirect ice-shelf effects explicitly discussed. Water-level drawing is exaggerated; it is not a sea-level forecast.

The 3D glacier uses original deterministic relief/material textures, fixed terrain and ice geometry driven by the same mass budget. It is not a named glacier, a reconstruction of an actual ancient ice cover or a scan. Studio lights, bounded orbit/zoom, capped DPR, on-demand frames and disposal are provided by `earth/threeStage.ts`. The 2D diagram and all controls remain available when 3D fails. Playback starts paused and uses the shared `earth/finitePlayback.ts` presentation driver. An explicit play runs at most twelve display seconds from round zero to twelve and stops; reduced motion advances in twelve discrete stages. Rewind retains input conditions. Changing conditions or views, leaving the figure, backgrounding, host pause and disposal stop playback; it does not resume automatically. Fast outputs are silenced while playing and announce the final observation on pause.

## State and sources

Validated state keys: `view`, `range`, `event`, `iceCover`, `snowReflect`, `accumulation`, `ablation`, `steps`, `glacierPhase`, `melt`, `iceLocation`. `steps` is the completed integer round (0–12); `glacierPhase` is a presentation fraction in thousandths (0–999) toward the next round, forced to zero at round twelve. It never represents years. Restoring either value is paused. Root query names are gallery-prefixed. The module owns its controls and cleanup; the museum owns navigation and URL framing. Exact references are shared by `content.json` and `learning.json`; the static bilingual entries remain usable without scripts. See the source-review ledger for chronology and model qualifications.

The workbench adds `scope=global|region|evidence`, `edgeDirection=advance|retreat`, `evidenceMode=seaice|snow|sediment|scratches|core` and bounded `samplePhase=0..100`: **15 total state keys**. `iceCover` remains the global observation coordinate. No playing flag is saved. Global `ice-edge` (18 display seconds), local `glacier-budget` (12 display seconds for twelve rounds) and `ice-sample` (12 display seconds) are mutually exclusive finite presentation clocks. Scope changes pause all clocks and preserve their separate phases. Samples P3–P5 only remove an observation cover, while P1/P2 illustrate uncalibrated structural changes. Textures, pore positions and provenance identifiers remain stable.

Only one WebGL context is mounted: the global stage is disposed before the valley stage is requested, and both are released for evidence. Late imports check their epochs. The globe uses 30,400 sphere triangles desktop or 12,096 narrow, plus bounded marker/ring geometry and a latitude guide. Two original 512×256 maps are baked once per module and uploaded once per mounted stage; no per-frame texture generation occurs. Globe uniforms and valley buffers update on demand. The HTML A badge updates on controls and host resize through one cancelable frame, and hides behind the sphere. Each failure path exposes its own visible retry while retaining URL state; diagrams remain usable without WebGL.

Tests cover distinct linear scales, budget closure, opposite ice responses, no loss of absent ice, floating/land mechanisms, deterministic rewind and malformed share input. Browser evidence is reported separately from numeric tests.
