# 仙人掌怎样留住水？

给沙漠下一场雨，看看胖胖的茎怎样储水，再打开白天和夜晚的窗口。

许多沙漠仙人掌以肉质茎的储水组织应对干旱，棱有助于随含水量伸缩；浅而广的根系可迅速利用短暂降雨。较厚的角质层减少表面失水，刺还可遮阴、改变表面气流。典型CAM植物主要在夜间开放气孔固定二氧化碳，白天利用已储存的碳进行光合作用。

## 教学边界

储水格数不是升数，也不是存活天数。图中茎的伸缩、气孔和根被放大；白天关闭、夜晚开放是典型沙漠仙人掌的简化，实际还受种类与缺水程度影响。储水在组织细胞里，不是可直接饮用的一池清水。
