# 矿物与晶体馆 · Earth Minerals

本专题是地球数字博物馆的独立馆，也是总馆 `minerals` 章使用的同一个原生模块。`reader.html` / `main.ts` 通过共享 `mountSingleGallery` 挂载 `mountStudy`，总馆懒加载同一导出；无 iframe、重复演示副本或外部资产请求。

## 六个设计问题

1. 核心问题：矿物如何由组成与结构区分，怎样形成，又怎样用多种证据认识和利用？
2. 可变条件：微观/宏观对象、相机、石墨层位移、三种成晶环境、变化速度、溶质供给、进度、标本、五项证据、品位、回收率、代币价格及成本。
3. 观察结果：层内连接是否保持、晶粒数量与尺度、无晶体/晶体/玻璃去向、相容候选与冲突线索、回收质量与收支。
4. 因果链：连接方式→性质；成晶条件与重排机会→材料去向；观测属性→候选冲突；给定原料与回收假设→取得多少有用物质→条件化的经济判断。
5. 最容易误解：把晶体外形当内部结构；把模拟进度当实际时间；把一个练习候选当鉴定证明；把含金属或收支为正当开采许可。
6. 边界与依据：虚拟性质取手册典型值，原子网络由可检验几何生成；石英形态、3D材质与成晶预算为明示的代表性教学创作。精确来源、访问失败和未核读材料见 [sources.md](sources.md)。

## 四间观察厅

- `structure`：默认直接加载3D钻石/石墨网络，可旋转缩放、键盘观察、推移石墨层；另看自制石英晶簇，明确对象与尺度已经改变。钻石有限片段由常规立方晶格基点生成，内点四邻居，键角满足四面体点积−1/3；石墨内点三邻居，三层交替平移表现代表性AB层叠。边缘截断，原子球/棒夸大；不解电子、力、摩擦或相变。2D连接对照与全部说明始终可读。
- `growth`：熔体、降温溶液与蒸发溶液三种形成条件；确定性可回退的材料预算，包含未过饱和不结晶与急冷玻璃。默认热液分支把同一母岩上固定根部的A–E五个代表晶体与预算份额连接起来，提供主动播放/暂停/重置/拖动/分步和终点重播；熔体与蒸发仍有二维材料图。石英仅为热液代表习性，不把五个主晶体当预测晶核数，不将三个通用模型都称为石英生长。不求矿物相图、真实晶体尺寸、晶面速率或温度历史。
- `evidence`：石英、方解石、石膏、石盐、黄铁矿、赤铁矿六种典型矿物。硬度区间重叠和演示密度区间重叠保留；其他编码筛除明确冲突，不产生概率。石膏主解理不等于仅有一组，石英与黄铁矿不绝对声称在任何条件下无解理。真实形态、污染、多矿物集合与未收入矿物不在筛选器内。
- `resources`：固定1吨原料，品位是原料中目标金属质量比，回收率是取回目标金属的比率。理想分离质量账保留剩余目标金属；代币预算明确不是真实报价、矿山经济评估、尾矿水账或开采建议。矿物/岩石/矿石/宝石可交叠，铝土矿不是单矿物种。附常见用途与环境代价。

## 状态与生命周期

`StudyContext` / `StudyInstance` 来自 `../earth/studyContract.ts`，所有查询、事件与写入限定本模块根节点。`parseState` 严格解析枚举和完整十进制数字；未知/畸形值回退，合法数值夹限。每次操作与初次挂载均回调完整状态。无自动播放、自动转动或音频。

完整17键：`view, representation, camera, exposure, occurrence, finish, shear, environment, rate, supply, progress, specimen, evidence, grade, recovery, price, cost`。

- `view`: `structure | growth | evidence | resources`
- `representation`: `carbon | quartz`；它们没有共同长度尺，切换不宣称同一物体连续放大。
- `camera`: 严格有界JSON `{"position":[x,y,z],"target":[0,0,0]}`；相机距离3–18、坐标绝对值≤30，旋转/缩放完成后保存。
- 0–100: `shear, rate, supply, progress`；`environment`: `melt | hydrothermal | evaporation`。
- `specimen` 为六矿物id；`evidence` 为固定顺序的逗号列表（`hardness,streak,cleavage,luster,density`）。
- `grade` 0.1–5%，`recovery` 20–95%，`price` 2–20，`cost` 20–300，后两者为虚构代币。

3D `scene.ts` 按需导入，结构与生长厅移动同一展品容器、复用同一canvas/context；离开这两厅才释放。生长切到熔体/蒸发时隐藏且暂停该场景，不创建第二context。异步epoch防止离开/销毁后晚挂载。`dispose()` 幂等；终止控件监听，取消晚到结果，释放几何/材质/纹理/环境贴图、observer、controls、render lists和context。

共享 `../earth/finitePlayback.ts` 仅提供18秒的展示时钟，不代表科学时长。初始暂停，只有用户主动播放才推进既有 `progress`；不新增科学状态键。每次由确定性的 `growthAt` / `quartzGrowthAt` 求同一快照，暂停/终点回调完整状态供父路由最终flush。拖动、条件修改、切室、`StudyInstance.pause()`、画面离屏、后台与dispose均停止；返回不自动续播。`prefers-reduced-motion`量化为12个阶段，手动上一步/下一步每次10个百分点。3D只改预建晶体及其内含物组的变换、既有druse实例矩阵和36个搬运标记的位置，二维SVG/预算节点也复用；不在播放帧重建几何或纹理。共享舞台继续按需渲染。

独立入口使用共享 `earth.minerals.<key>` 路由合同，保留 `?lang` 与其他展馆的状态；父馆/独立馆/相邻馆回链由 `singleGallery.ts` 统一维护。浏览器前进后退重新挂载保存状态。父馆负责其章节的完整路由、懒加载、错误恢复和生命周期。

## 3D形态与资产

`geometry.ts` 负责可测试的碳连接。`scene.ts` 自制石英晶簇：六面柱体与简化尖端、平坦晶面法线、细横纹、有限内含物/薄雾、带颗粒/脉纹/铁染的连续母岩、根部小晶芽与克制展台。外形不是实物扫描，没有面指数或真实尺寸保证；光学是实时材质近似，未求石英双折射、光谱或多晶体精确光路。没有靠图片纹理冒充定量晶格。主/辅灯、反射环境、相机距离和材质区别微观编码与宏观形态。

3D资产、SVG与256×512灰度生长纹、512×512母岩纹理/背景及128×128内含物薄雾由代码生成，无纹理/模型网络下载；Three.js、OrbitControls为MIT依赖，自制softbox场景经PMREM生成反射环境。封面与来源由总馆整合任务维护，见 [COVER.md](COVER.md)，封面也不是观测或鉴定证据。

## 性能与验证

共享 `createThreeStage` 按需帧，桌面DPR≤1.5、窄屏/触控≤1.35；几何细节按设备分级，纹理上限512×512，含256×512生长纹与128×128内含物纹理。碳网络用InstancedMesh共享球和棒几何。默认无持续动画，减少动态不移除机制或最终结果。

`exposure`（0–100）只调整围岩教学显示，`occurrence`（vein/geode/pocket/grain）比较不同代表剖面，`finish`（natural/cut）控制独立表面来源对照，不切磨原3D晶簇。仅裂隙的A锚定上方同一晶簇；其他环境不暗示同一对象改变赋存。

模型验证：`node --import tsx --test topics/earth-minerals/tests/*.test.mjs`，11项覆盖严格初值/相机、熔体/溶液守恒、不同去向、可逆快照、固定晶体身份/锚点及预算驱动形态、多证据单调筛选、资源预算、钻石四面体和石墨蜂巢。

实际浏览器记录与局限见 [VALIDATION.md](VALIDATION.md)。类型/双语/全局构建由整合任务运行；本馆写作保持三学术/四解说契约，正文包含完整分层静态内容，不以`learning.json`长度代替本馆深度。
