# 矿石与成矿路径馆 · Earth Ores

本馆由同一个 `mountStudy(host, StudyContext)` 服务总馆 `ores` 与独立馆。只拥有本目录的科学模型、内容、场景与控件；`main.ts`、`reader.html`、封面、登记和跨馆导航由父整合任务维护。本馆不修改已冻结的矿物馆；只复用它的纯经济预算函数，没有复制UI。

## 六个设计问题

1. 核心问题：有用物质怎样被输送、保留或分选，为什么看见矿物也不等于认定经济矿石？
2. 可变前提：热液通道/金属供给、风化强度/有效排出、砂矿解离/水流情景、各路径独立进度、形成/标本视图、观察切面、三类证据，以及独立的经济假设。
3. 观察结果：来源标记留在来源/通道/矿脉的不同去向、选择性淋失后的相对组成、固定河床窗中重颗粒的停留或再搬运、同一实体不同切面，以及给定回收条件下的收支。
4. 因果链：来源→通道/反应→相对集中→自然赋存与标本→多证据→加工用途与代价。三条成因互为对照，不是一块矿石必须经历的顺序。
5. 最易误解：白脉必有金属、红土必为铝土矿、所有黑砂含锡、重矿物永远不走、混合矿石有一个单矿物硬度、漂亮标本代表整矿体、正代币余额等于开采许可。
6. 边界与来源：图形与材料追踪为明示教学构造；典型矿物性质来自公开手册，形成方向由USGS/博物馆资料交叉支持，见 [sources.md](sources.md)。没有实地勘探、化验、相图、河道、储量或现实经济预测。

## 三条实做路径与扩展方式

- **裂隙热液矿脉**：同一36个来源标记（8金属来源、28硅质来源），有通道才能进入。缺少金属输入时，金属来源留在来源，石英脉仍可形成；封闭时都不进入。标记代表来源批；最后接近目标时以连续`depositedFraction`表示批内渐次沉淀，账本分别报告尚在来源、迁移/部分沉淀、已完成整批以及两类批内平均份额。份额不是实测质量、体积或品位。温压/化学作用合为一个代表性允许沉淀情景，不设伪精确温度。3D是同一矿脉取样窗口A中的闭合围岩实体，固定空间材质场包含主脉、支脉、金属状斑块与细粗糙度；不是悬空完美晶簇。
- **风化残积铝土矿**：保留同一30个来源标记，分为12含铝、6其他较保留（如铁钛相关）、12较可迁移。有效风化和排出才使可迁移标记出剖面；含铝绝对数量不增加，剩余中相对份额提高。来源不等于原晶体永远完整。标记比例不是Al/Al₂O₃品位，铝土矿是混合材料；豆状结构只为一种代表形态。
- **流水锡石砂矿**：固定6锡石和18石英，图中相同代表粒径。先解离再谈单粒分选；弱水流未完成搬运，选择性情景使6重颗粒留在固定床窗、18轻颗粒出窗，更强流使两类都出窗。固定粒子ID与窗外记账避免物质消失。实际粒径/形状/黏聚/湍流均可改变结果，此处不求流速阈值或沉降。

每条都有结构/产状、典型性质与矿物组成、成分/代表性取样三个证据窗口，以及加工用途和环境代价。矿物种、岩石组合、经济矿石和宝石用途品质是交叠视角。未来类群沿“形成—赋存—结构/观察—证据—用途”扩充；本馆暂未模拟斑岩、矽卡岩、块状硫化物、沉积铁建造、煤层或蒸发盐，不生成空卡片假装穷尽。

## 状态、模型与生命周期

完整18键：`process, view, veinProgress, bauxiteProgress, placerProgress, fluid, fracture, weathering, drainage, flow, liberation, evidence, cut, grade, recovery, price, cost, camera`。

- `process`：`vein | bauxite | placer`；`view`：`process | specimen`。默认热液手标本、已展开进度100，用户可回到来源；没有自动播放。
- 各自进度0–100，无标定地质时钟；切换路径保留各自进度。
- `fluid=rich|poor`，`fracture=open|sealed`，`weathering=intense|weak`，`drainage=flushed|closed`，`flow=weak|sorting|strong`，`liberation=free|locked`。
- `evidence`为`texture,properties,analysis`的固定顺序子集；`cut`0–100独立控制观察面，不能代替形成进度。
- `camera`严格解析为有界三数JSON位置，半径3–15。`grade`0.1–5%、`recovery`20–95%、`price`2–20与`cost`20–300（虚构代币）。

初值只接受完整枚举/完整十进制串，畸形值回退、合法数值夹限；首挂载和每次操作均回调完整状态。18键在父馆上限20以内。控制/事件/查询限定host内根`.earth-module.ores-study`；样式全部限定`.ores-study`。

共享`finitePlayback.ts`仅驱动呈现时间，科学过程仍由本馆模型拥有。必须主动播放；完整0→100约18秒，只压缩过程次序，不能换算真实地质耗时。暂停/重置/拖动、切换路径/观察方式/前提、画面离屏、后台、实例`pause`与`dispose`都会停时钟，恢复路由不会恢复播放。减少动态时量化为10个阶段，仍可随时手动拖动。风化/砂矿标本视图的按钮明确写“回到形成剖面并播放”；热液3D可直接观察填充。播放状态不持久化，当前进度仍用原有18键完整回调。根适配器负责URL写入限频。

3D仅热液手标本视图按需加载，其他视图为SVG；同一场景只开1个context。切出立即释放、晚到import通过epoch丢弃、dispose幂等。`pause`同时停有限播放和按需舞台；后台/不可见由共享生命周期停止，用户主动操作可恢复。3D失败保留2D过程和文字，重试用完整已保存URL的`location.reload()`，处理Chromium同文档失败import缓存。

`model.ts`拥有材料身份/条件与预算；`scene.ts`自制同一闭合实体、稳定三维材质场、剖切几何与光照；`study.ts`只投影模型与双语内容。经济预算复用`../earth-minerals/model.ts`纯函数`oreBudget`：1吨原料、理想分离、给定金属品位/回收率、虚构价格/成本，和上方标记数无关。正余额不确定储量、许可或环境合格。

## 自制资产与几何边界

矿脉围岩轮廓、表面起伏、曲折主脉/支脉和硫化物斑块均为程序构造，无外部图像/纹理/模型。改变观察切面时，前表面露出新的深度并采样固定空间材质场，后表面和围边保持；纹理不跟镜头漂移，不每帧重新随机。播放以连续来源批份额控制固定场的显露，蓝灰带示意通道中输入迁移；显露次序、带的方向和速度均非实测流向、流速或晶体生长方程。3D只更新uniform，切面没变便不改几何；SVG来源标记也保留同一DOM节点。A表示同一取样窗口区域，不承诺同一个原子。材质区分暗色围岩、较浅石英脉和金属反射斑块，但它们不是实测成分或晶格数据；不由外壳猜晶格。3D单位没有实物标尺、产地、测地或扫描保证。剖切为观察对照，非儿童切磨/采集教程。

Three.js与OrbitControls为MIT依赖；自制softbox经PMREM生成反射环境，target独立释放。程序材质无纹理网络请求，只有环境贴图在场景内；几何按窄屏/触控分级，DPR由共享舞台限制≤1.35（窄屏/触控）、≤1.5（桌面）。桌面/手机目标预算60k/25k三角形；最终实测见 [VALIDATION.md](VALIDATION.md)。播放内容最多15次/秒更新并请求渲染，停止后没有持续时钟或render loop；无自动旋转或音频。
