# 小小百科

以互动演示为入口的亲子百科。每个专题有自己的画面、知识讲解和参考资料，目录负责分类、搜索及导航。目前只有一个已完成专题：**恒星路过黑洞**。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173 --strictPort
```

- 百科目录：<http://localhost:5173/>
- 黑洞专题：<http://localhost:5173/topics/black-hole/>
- 构建产物：`dist/`。按目录整体托管，每个专题有真实的 `index.html`，支持直接访问与刷新，无需 SPA 路由回退。

## 当前框架

- **目录**：五个分类、关键词搜索、可分享的筛选链接，每次最多显示 24 个条目。未发布专题不进入目录；空分类明确提示暂无演示。
- **独立专题**：每个专题拥有入口、动画、知识、资源与测试。进入专题才加载该页的代码。首页不加载 Three.js，不计算气体轨迹。
- **自适应外观**：默认跟随内容；全部目录和多数分类采用浅色，宇宙分类与黑洞专题采用深色。读者可选择浅色或深色，偏好保存在本机。页面外观与画布背景分开，黑洞画面始终保持深色。
- **统一导航**：专题提供返回首页、分类和外观设置。动画控件归各专题所有；无需为所有知识强制使用黑洞的时间轴。
- **轻量内容登记**：`content/catalog.json` 是分类与专题元数据的单一来源。构建从已发布条目生成多页入口，并检查标识、分类、主题与入口文件。

黑洞原有四种路线、儿童版与学术版、两分钟瓦解过程、持续内落、暂停回看和可选配乐均保留。模型限制和 NASA 资料见 [专题说明](topics/black-hole/README.md)。

目录目前使用浏览器本地筛选。专题数增长到需要更复杂检索时，可独立替换目录检索方式，不必修改现有动画。当前没有账户、云端学习记录、内容管理后台或离线缓存。
