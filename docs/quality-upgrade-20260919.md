# 2026-09-19 过程观察与发布验收

本轮检查目录中 60 个已发布主题的演示入口、观察任务、双语讲稿及知识层次，优先补强过程被静态切换替代的 17 个主题。不会把所有主题机械地换成同一种动画：已能持续观察、调参、暂停与多视角比较的演示保留自己的模型和表现方式。

## 深度改进范围

| 主题 | 主要检查与改进目标 |
| --- | --- |
| 影子、声音、太阳、绣球 | 连续几何、介质往复与传播的区别、条件变化、可控观察 |
| 鸭脚、鱼鳃、伪装、种子旅行、植物输水、仙人掌 | 推进与回收、气体交换、运输路径和生理条件；完整过程与回看 |
| 河流、沙子、地下水、自来水、摩擦 | 同一批物质的连续路径、去向保留、过程暂停、微观机制 |
| 蝴蝶、花与果实 | 羽化后翅膀准备；花粉接触柱头后才留下并萌发，授粉与受精不混为一步 |

蝶翅演示仅解释羽化后的展开与等待硬化，不把成虫准备画成立即飞走。四阶段仍是回看观察记录，不虚构不同解剖结构之间的连续变形。整体与局部镜头共享进度。

樱桃演示中花粉和蜜蜂一起移动，接触柱头后花粉保留在原处，蜜蜂随后离开。花粉管在接触之后生长，果实发育发生在之后；24 秒压缩了不同长度的真实过程。播放、暂停和拖动回看共用状态。相容且成功受精是这个例子的前提，并不声称每次授粉都能结果。
