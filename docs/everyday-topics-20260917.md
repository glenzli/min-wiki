# 2026-09-17 日常家电与电池专题

新增三项可以从家庭经验出发的中英双语专题，目录从 56 项增至 59 项。三项均归入科技与工程，可用“日常科学 / Everyday science”检索。每题包含原创插画、可暂停的互动观察、儿童版和学术版、三节深入笔记、四段独立口播及画面提示。

- `air-conditioner`：房间与室外、透明冷媒回路、室内机近景共用同一场景。区分空气、冷媒和冷凝水；比较制冷和只送风。能量账表达一个循环的取热、压缩机功与放热，数字是示意，不用于评价真实能效。冷媒相态、压力与路线由专题模型持有。
- `refrigerator`：同一台冰箱的外观、透视与管路镜头；食物和箱内空气有不同的热响应，压缩机按上下阈值启停。比较始终关门和中途开门再关闭的两条时间线，同时展示闭合冷媒回路。温度、热容量和时间是教学参数，不提供食物存储时限建议。
- `batteries`：玩具回路、放大的电芯与马达。开关真正接触后才允许放电；开路停止能量输入，马达可以短暂惯性转动。内部明确以锂离子电芯为例，外部电子和内部离子各走不同路径，能量来自化学状态改变。一次电池与适配可充电电池的区别另行说明。

主要依据为 DOE、Natural Resources Canada、OpenStax、Danfoss 和电池科学的一手资料；具体链接随专题维护。全部是教学演示，未声称复现某一商品的实测性能，也不要求儿童拆电器、拆电池或接触市电。
