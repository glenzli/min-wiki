# 宇宙知识体系扩展 · 2026-10-23

本轮授权为本地设计、并行开发与验收。三个子 agent 使用 GPT-6.1 Sol、max 推理强度，分别拥有小天体、恒星星云、星系尺度专题；主任务拥有教学导览、目录注册与整合验证。浮力与火山同时有其他任务改动，不归本轮所有。

## 分类与学习顺序

保留 `universe` / 宇宙与星空这一顶层分类以及全部旧路由。新建 `universe-guide`，先区分天体、物质、系统、事件和观察者限定的范围。23 个代表对象提供光源、所在层次、辨别线索与对照对象，再连接四条路线：

| 路线 | 核心问题 | 所属专题 |
| --- | --- | --- |
| 太阳系里的世界 | 同在太阳附近，结构、轨道和活动为什么不同？ | solar-system → small-bodies → meteors；earth-moon 保留独立几何观察 |
| 恒星的一生 | 初始条件如何改变形成、能量来源与结局？ | stars 的星云、演化、恒星类型；分支不强行串为同一条必经路线 |
| 引力与极端天体 | 同一种引力怎样产生不同运动和物质去向？ | stars 的双星/三体 → black-holes；致密遗迹从恒星历程交叉进入 |
| 星系与宇宙 | 熟悉对象处在什么结构与物理尺度中？ | cosmic-scale 的大小、归属、星系形态与连续缩放 |

导览是分类与证据比较。用户实看白矮星后指出原辨认符号太小、画面过于空泛，因此导览改为自己拥有的非比例三维辨认图和简化能量剖面，并将分类与文字压缩到画面外围。物理过程模型、时钟和定量尺度仍由各专题拥有。不把导览做成新的总模型，也不利用 `parentTopic` 假装所有专题已经融合；它目前只允许同分类的一层真实整合关系。

本轮新增职责分别由 `topics/universe-guide/README.md`（名词类别、对照与路线）、`topics/small-bodies/README.md`（小天体模型与3D观察）、`topics/stars/README.md`（星云与恒星演化）和 `topics/cosmic-scale/README.md`（星系结构及原有尺度）说明。共享平台只增加内容资源注册与本地化，不接管天文学模型。`SKELETON.md` 同时由浮力任务持有，本轮不覆盖其编辑。

## 三维化的取舍

- 小天体：形状与照明、彗星轨道和两种尾巴、稀疏带与碎屑流的空间关系适合 3D。奥尔特云单独注明推断与非共同缩尺。
- 恒星：物质云、原恒星/盘、膨胀外层与致密遗迹适合可转动的结构示意；真实半径比较继续用统一投影。星云的发射、反射、遮蔽必须区分。
- 星系：同一固定星群正面、侧面与斜视比较，旋涡、椭圆、不规则形态以及星团的成员层次。形态分类不是时间轴。
- 既有太阳系、地月与黑洞已拥有 3D 几何；本轮以互相导览接入，不凭技术名称声称重新验收它们全部旧场景。
- 尺度与因果图仍可平面展示。小于像素的天体使用定位符，不能为可见而悄悄放大物理直径；可观测范围不是宇宙墙。

## 可观察性与资源策略

每个实验至少提供一个可变条件和有意义的对照，镜头状态与科学进度分开。将对象形态、关键过程、尺度说明和操作置于主画面附近，详细推断与限制留在解说。禁止用动态纹理和粒子数量替代物理关系。

几何和纹理稳定生成，资源有上界；切章停用无关动画，页面隐藏停止更新，减少动态偏好仍能操作。加载失败需保留文字、有效导航及静态对照。性能记录区分首次准备、稳定交互和重复切换；没有实测则不承诺帧率或提升百分比。

## 验收与状态

新增专题及广泛整合需要 `npm run check`，并检查生产 Reader 产物的中文/英文、桌面/390px、关键前中后状态、旋转与条件变化、旧链接、返回、暂停及失败路径。新入口先标为草稿；通过模型与构建不能代替画面验收。实际证据另见[本次视觉记录](strict-visual-review-20261023.md)与各专题 VALIDATION 文档。

不自动将现有草稿升级为完成稿；不提交、推送或部署。最终交付明确区分本轮改动、执行过的验证、实际目视范围与剩余限制。

本轮实看后实施的修正包括：移除两个新入口的重复大标题；银河与小天体扩大主观察区并外移标签；星团连接线使用真实对象变换；星云保留同一不规则密度结构以比较照明；遗迹使用透明外壳和较清楚的细丝；演化标题随当前阶段更新；小天体的实验设置保留一层展开。

## 后续跨专题同步与大小顺序修正

用户进一步要求更好的外观进入恒星专题，并审查其他天体。纯恒星/星云材质职责提升至 `src/visuals/`，由导览与恒星研究共同消费；科学参数、形成过程、照明机制与时间仍由各专题拥有。

用户明确允许压缩真实比例，但同框对象的大小关系必须正确。导览对太阳/地球、木星/地球、木星/海王星、地球/月球、谷神星/代表小行星、红矮星/白矮星保留大小顺序，切换主次与窄屏不改变它；不指定质量的黑洞、广延结构和事件使用分开的近看窗口。小天体、系统归属图和黑洞的轨道参考图也检查太阳/行星/彗核的大小次序。已有真实直径/轨道标尺的视图继续保持其定量合同。
