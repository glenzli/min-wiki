# 演示优先布局检查

## 展示原则与修复

71 个已发布入口统一通过 Reader 查看，包含 46 个独立主题与 25 个兼容入口。演示占据主区域；目录、章节、讲解方式、完整说明与次要设置按需打开。播放、进度与必要状态留在演示旁。

此前移除站点外壳的内边距后，部分说明、原生折叠区与章节导航仍依赖旧页面留白，只修补学习组件不能覆盖整页。现在由 Wiki 显式标记非演示的阅读区，Reader 统一提供左右内边距和紧凑纵距：桌面最多 32px，手机 16px；嵌套阅读区和演示侧栏避免重复内缩。学习区移除旧的居中宽度限制，与前面的说明和导航对齐，正文内部保留合适的行宽。

56 个模板文件增加 232 处 `data-reader-prose`，黑洞尺度章节动态生成的追问区另增加一处。逐文件比对确认：移除新增标记后，这些模板与本轮修改前完全相同；动态章节仅增加该属性。科学文案、参数、图形、控件标识和实验状态没有随排版调整改写。

章节菜单原先只处理按钮和下拉选择的收起，链接选择会留在展开状态；现在点击章节链接也会收起并把焦点交回菜单。调节和播放控件继续保持原有行为。
