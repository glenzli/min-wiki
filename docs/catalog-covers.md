# Catalog cover illustrations

Updated: 2026-09-18. These are educational illustrations, not observation photographs.

The catalog uses one visual direction: detailed natural-history subjects, tactile materials, soft directional light, restrained colors and a clear central subject in a 3:2 frame. The 11 remaining diagram-like SVG covers now have illustrated companions that match the existing series. Original SVG fallbacks remain available.

Each new cover was generated with the built-in `image_gen` tool in new-image mode. Full generation prompts, original output paths and scientific simplification notes are recorded in the linked topic files. JPEG masters are 1200 × 800, quality 85; responsive WebP delivery is generated centrally by `scripts/optimize-images.mjs` at 480 and 960 pixels. The catalog uses `srcset` and lazy loading.
