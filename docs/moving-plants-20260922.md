# 会动的植物：范围与验收记录

日期：2026-09-22。起点：`c0f9aa6aad920f42f62c2de8bbb75734f7b47b3b`。
本次把含羞草扩成三站植物运动系列，保留 `/topics/mimosa/`、原模型、叶枕与细胞观察。
只修改该主题、目录和对应英文元数据；没有改动其他主题的科学模型。

## 学习路径

共同问题是“没有肌肉的植物怎样动”，每站使用不同的触发条件和机制：

| 观察对象 | 孩子可以改变什么 | 应当观察到什么 | 动作来源与边界 |
| --- | --- | --- | --- |
| 含羞草 | 羽片位置、局部/较广刺激、观察尺度、进度 | 局部小叶合拢与主叶枕响应不同；放大仍是同一组织和细胞 | 离子、水分、膨压与连续组织形变；原有模型保留 |
| 捕蝇草 | 一次短触、两次短触及间隔、动作/机制视角 | 一次通常不夹；近时两次先累积信号再闭合；隔久两次保持张开 | 电信号、钙信号和快速叶片形变；30 秒是教学窗口，非通用硬阈值 |
| 幼苗 | 左光、右光、两侧光、整株/同一茎段、进度 | 与一直受两侧光的幼苗比较；两侧都长，伸长差使茎弯曲 | 幼茎向光性；不是关节转动，也不是光把整株拖过去 |

四岁孩子可先猜结果并操作按钮；小学生可以做成对比较；初高中及成人可展开机制、
相对读数和学术笔记，区分膨压运动、信号整合后的快速变形与差异生长。
这些是设计上的阅读层次，未声称完成不同年龄儿童的实际可用性研究。

原始研究、模型边界与中英讲述稿同步进入主题 README、页面和 `learning.json`。
没有增加“植物像人一样害羞或思考”的暗示；一次缓慢弯毛也可能产生多个电信号，
因此捕蝇草并非所有情况下都要机械地“数到二”。幼苗结论不能直接套用到根或所有器官。

## 交互与所有权

- `main.ts` 管三站选择、地址和共享展示模式；无参数或无效 `plant` 参数回到含羞草。
  `?plant=flytrap` / `?plant=seedling` 可直接打开相应站。
- `movementStudy.ts` 管两项新实验各自的条件、时钟、暂停与清理；切换植物保留各自状态，
  改条件开始新实验，换视角不重置。播放由用户启动；隐藏文档会暂停新实验。
- `movementModel.ts` 管捕蝇草信号衰减与触发、幼苗两侧伸长和曲率。
  信号达到触发条件与可见闭合之间有独立的过渡状态。
- `movementScene.ts` 管教学绘图。幼苗放大视图取整株金框中的同一段连续茎，
  不把整根茎替换成另一个器官；配对幼苗是对照样本。
- 使用现有 `mountObservationMode` 收起解说、进入沉浸及按 Escape 返回。
  桌面减少页头与非必要信息占用；手机沉浸时，解说作为可关闭的覆盖面板。
- 目录只有一个“会动的植物”入口，含羞草和捕蝇草关键词都可检索；原路径和封面保持有效。

## 限制与交付

捕蝇草绘图为投影示意，没有求解真实壳体弹性、消化、猎物或数小时后的重新打开。
幼苗相对长度、弯曲和细胞示意未按实测标定；未模拟生长区异质性及其他向性。
两项实验的播放时间不同于真实生物时间；拖回和重新实验是回放，不是生物瞬间恢复。
本次没有加入昼夜睡眠、藤蔓缠绕等额外站点，也没有改造全站所有主题的布局。

用户已授权本地提交，并要求后续使用实际当前时间，因此不再设置历史提交日期。
验证后通过 Dev Mesh 管理的直接提交完成；提交哈希以 Git 记录为准。
本次没有推送或部署。
