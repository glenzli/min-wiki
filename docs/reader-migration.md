# 全量切换到 Wiki Reader

Mini Wiki 现在维护内容和科学演示，唯一展示工具是独立的 [Wiki Reader](https://github.com/glenzli/wiki-reader)。`wiki.json` 登记全部 **71 条发布路由、41 个目录主题**，包括已整合子条目和暂不列入目录的旧链接。原站首页、Vite 配置、专题整页 HTML 与导航/主题实现已移除。

## 迁移边界

每个条目提供双语 Markdown、`reader.html` 实验片段和原专题控制器。SVG、Canvas、WebGL、Worker、多章节和独立时钟继续归内容仓库；内部 `study.html`、`panel.html` 没有被外层入口覆盖。首轮四条目组件试验已统一回原生文档入口，避免维护额外适配层。

Reader 提供黑白灰明暗界面、目录、搜索、专注/只读模式、通用说明区、预览和静态构建。科学画布的材质、光谱和图例颜色由专题保持。正文从原 `learning.json` 投影到有标记的 Markdown 区间，完整保留三节笔记、误解、模型边界、来源、四段解说和分镜；区间外仍可手写。

已合并远端 `ad7603e` 及此前的交互修正，包括新增的电路、程序、AI、飞行和移动网络专题。地月比例观察、浮力受力说明及原有科学限定条件随原控制器保留。

原生演示每次打开具有完整文档生命周期。专注保持当前实例；只读打开不加载演示模块的新文档。语言切换、重新进入的恢复范围由各专题 URL 合同决定，不承诺任意瞬间存档。旧链接继续由专题路由选择对应章节，保留有效语言、base、参数与锚点。

## 日常使用

```sh
npm ci
npm run dev
npm run prepare:entries  # 修改 learning.json 后
npm run check
npm run build
```

Reader 由依赖锁定到具体 Git 提交；可用 `WIKI_READER_ROOT` 显式覆盖为另一个工具检出。`scripts/wiki-reader.mjs` 只定位并调用外部工具。输出统一是 `dist/`，不保留第二种站点构建。

独立 Reader 项目附带 Codex 的 `$preview-wiki` 技能和本地插件市场。它自动选端口、复用经过身份核验的预览，也能查询和停止自己的实例。预览本身不提交、推送或部署。宿主 glenzli 的同步、点赞和部署仍需另行接入新输出；本次全量迁移不发布在线站点。
