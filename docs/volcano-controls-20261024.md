# 火山操作区样板 · 2026-10-24

## 范围与行为

以 `58c2b486d9ab71e3e5c98b7c19c9df48cc99955f` 为干净起点，只调整火山专题及其控制边界。大气、恒星、电路用于前期结构比较，本轮没有迁移或修改它们。地质模型、材料、喷发条件和各问题的时间尺度不变。

- 主工具栏分为当前问题、镜头、剖面、改变条件、讲解。当前问题直接显示名称；题目菜单只放七个问题，儿童/学术阅读深度移入讲解。
- 喷发机制与喷发形式的相机、切面是独立参数。同一全山视角可以直接开关剖面；喷口近景也能保留剖面。关闭地下近景的剖面时回到完整山体，避免让镜头留在不透明围岩内。场景资源、材料与过程进度保留。
- 造山、海底、草坡、湖与地热通过原场景支持的镜头/剖面状态接入同一操作栏；热泉和湖没有多余的单选镜头，镜头菜单只提供复位与过程提示。它们仍使用原有的相机预设，不宣称每个渲染器都新增了任意镜头与任意切面组合。
- 原始条件节点及其监听器整体移动到独立条件面板，未复制输入或创建第二份状态。桌面面板锚定工具栏，手机从底部展开；条件与讲解互斥展开，Escape、点击外部和关闭按钮可收起，关闭恢复触发控件焦点。
- 阶段跳转、倍速和从头观察收进原进度条旁的菜单。镜头复位不会重置过程；从头观察才回到过程起点。可见播放文字缩短，无障碍名称仍明确控制“过程”。
- 镜头、切面、进度与非默认有效条件写入网址，切语言/刷新后恢复；原有 case/chapter 入口、问题默认进度及语义保留。选择新的地下活动情境仍明确从起点开始。各问题在当前访问期间继续保存独立状态。
- GPU丢失后仍显示静态说明；不支持的剖面切换显式禁用。重试保留原过程、镜头、切面偏好与细节运动设置。

`observationControls.ts` 只拥有控件节点、面板、焦点和事件生命周期。`main.ts` 继续拥有问题、条件、进度和场景协调；`studyModel.ts` 验证公开观察路由。`scene.ts` 保留失败恢复边界，`eruption3d.ts` 消费独立切面参数。没有改写共享 Reader 或增加另一套播放器。
