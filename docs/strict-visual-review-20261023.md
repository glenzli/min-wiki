- 太阳与红矮星采用随对象转动的颗粒亮纹、代表性暗斑、临边变暗和有限辉光；白矮星使用较平滑的蓝白热光。默认保留完整外观，能量示意是另一个可选视图，继续区分核心核聚变与白矮星储存的热量。
