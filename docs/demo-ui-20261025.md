# 演示操作区整理（2026-10-25）

本轮先提交已验收的火山操作区，再以同一原则整理大气、恒星与电路。48 个独立主题的静态控件入口已梳理；这是入口盘点，不代表 48 个主题都经过视觉验收，也不改变成品／草稿判断。

## 操作分工

- **选问题**：问题少时直接展示，例如电路的两个问题；恒星的六个问题共用一个选择入口。
- **改条件**：分支、参数和阶段选择单独展开，不与讲解深度混在一起。只在适用的问题中显示，例如手动电路不显示感光条件。
- **看过程**：播放、进度、直接操作实验对象的按钮保留在画面旁。关闭剖面、改镜头、暂停动态与重置实验各自保持明确语义。
- **读讲解**：儿童／学术切换、读数与科学边界放在讲解面板。小屏展开后直接可见，不要求先滚过整个场景寻找内容。

常用操作不因“紧凑”而一律藏进菜单。保持 44px 的主要触控目标，顶栏为一排或窄屏两排；需要展开的内容临时占用空间，关闭即回到观察。原节点与原事件只挂载一次，保留实验的科学状态与资源生命周期。

## 本轮范围

| 主题 | 具体调整 | 保留的实验语义 |

未为每个主题强加同一组按钮，也未改动其他主题的科学模型、审核状态、路由目录或 Reader 依赖。

## 验收方式

执行三个主题的既有针对性测试，以及类型、双语消息、图片、条目投影和审核元数据检查。真实浏览器检查中英文桌面与 390×844：菜单收起、控件遮挡、展开面板位置、条件保留、恒星进度保留、感光导致灯亮与回线断开导致灯灭。最终全量 Reader 构建的回执与输入哈希另存本地验证目录，提交与部署分别记录。
