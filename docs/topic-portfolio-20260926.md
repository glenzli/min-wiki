# 专题收录与精修蓝图

## 收录决定

本轮收起 `lunar-craters`、`meteors`、`sand-journey`、`camouflage`、`tap-water` 五张卡，目录保留 36 张。它们仍为 `published`，直接 URL、知识资料和生产构建保留；`listed: false` 只控制目录、分类计数和搜索。旧页面没有因此被改良，也没有假称已合并到别题。其余 25 条原有子入口维持 `parentTopic` 与旧 URL。

收起的依据不是“短”：影子、磁铁、鸭蹼和洗手有明确的独立实验与可见的条件差异，继续收录。五题的问题分别是两个碎片题的因果链分散且画面难以辨认、沙粒成因主要按进度插值、伪装近乎静态找图、自来水虽有非检测提示，但符号处理画面仍可能让儿童误认为在判定这杯水，且供水屏障机制未被呈现。恢复收录需要满足下文相应的具体门槛。

## 共同的制作与验收标准

1. **先定知识，再定镜头。** 每题写出一个核心问题、前置条件、机制、结果、反例或失败分支、最易误读的地方。短题做到这一点即可，不凑章节数。
2. **让孩子追得上同一对象。** 从整体到剖面、从现场到放大、从一天到多年，用固定标记、位置、颜色和状态连接镜头。不同物种、不同样本或反事实副本必须明确换了对象。
3. **每次操作都改变可见的原因与结果。** 有“变大／变小”的滑块却总抵达同一结局，就不足以成为交互。预测、操作、对照、回看应服务该题自己的因果链，而不是统一套模板。
4. **画面先于卡片排版。** 1280×720 的首屏要看得见主对象和第一个可操作问题；390 px 中英文要读得懂主对象、标注与控制。画面内只留必要标注和图例，长说明放旁边或下方；局部放大有锚点与倍率／示意提示。
5. **每题有自己的视觉语法。** 宇宙用天体身份、线性标尺与有依据的光；地球用同一地点的地图、剖面与流向；生命用可辨组织、显微层次和同一个体的历史；物理用可读的实验台、参照线与测量；工程用真实边界、路径和能量／物质去向。色彩、材质、注释、控件为对象服务，不用一套通用发光玻璃卡覆盖所有学科。
6. **示意与测量分清。** 对数镜头、放大颗粒、假色、预设轨迹、时间压缩、理想实验和真实观测分别标明；中英两版保持相同限定。模型测试证明程序遵守假设，不证明自然界一定如此。

近期 [Opus 5.5 的 100 个独立 HTML 展示](https://miaai-lab.github.io/Claude-Opus-5.5-100-HTML-Files/) 给出的可用启发是强主体、专属材质、贴近对象的注释和读数、控制与画面同步，以及整体构图的完成度。例如波纹实验把探针读数接在波场旁，DNA 页将引线标注连到结构，机械星图把操作装置做成主角。这里借鉴表现手法；科学数值、比例、机制和来源仍由各题自己的证据决定。漂亮的程序生成纹理不能替代模型。展示集是第三方作品集，不是科学准确性背书。

制作顺序：**P0** 修当前首屏主体太小／空白／被折到视口外的问题；**P1** 做跨镜头的因果和状态连续；**P2** 精修材质、注释、交互手感与中英窄屏。P0 是编辑优先级，不代表该题的科学价值高于其他题。每题验收至少看起点、中段、终点和一个条件分支，往返拖动、切章返回、中文／英文桌面及 390 px；旧入口还要看直达与刷新。

## 宇宙与星空

三项参照：`cosmic-scale` 负责从地球连续到可观测宇宙，同时区分同一帧真实长度与结构示意；`stars` 负责恒星形成、能量、晚年分支、太阳表面及多体模型；`black-holes` 负责黑洞本体、不同遭遇与尺度。它们的动态细节也必须接受上述科学边界与浏览器验收。

| 题目与决定 | 孩子最终应串起的知识 | 主画面、操作与精良门槛 |
| --- | --- | --- |
| `solar-system` 太阳系 · 保留／P0 | 太阳与行星的层级、公转、真实直径差异 → 固定一颗星球逐步接近 → 表面、内部、卫星和环。 | 首屏放大可辨识的太阳系关系，避免八颗行星挤在约一条细线上；选中的星球、位置和进度贯穿远景、下降和剖面。大小／距离／质量／密度比较各用自己的标尺，气态星球不落到伪地面。切换观察镜头不得无提示重置进度。 |
| `earth-moon` 地月 · 保留／P1 | 同一月球受光与观察位置变化 → 月相；自转与公转关系 → 为什么总看到相近一面；直径和轨道距离是不同尺度。 | 把同一月面特征作为轨道和地面观察窗的锚点；拖动月球时地面月相同步变化。可叠同日地球／月球视角与日光方向，标出夸大的月盘及不等比例的距离。 |
| `lunar-craters`＋`meteors` · 暂收起，拟合成「太空碎片的两种结局」 | 从相同初始碎片做**两份反事实副本**：进入有大气的地球，可能发光、消散或留下陨石；撞向近乎无大气的月球，则有撞击、抛射与坑的留存。 | 未来只做一个主入口，先看太空碎片，再平行观察两种环境，最后放大高空加热／月面剖面。抛射与坑缘必须可辨。大小、角度和速度仅控制定性分支；不得把现有预设轨迹、存活量或坑径当精确预测。两个旧 URL 届时各落到对应分支；完成前继续保留原页。 |

## 地球与自然

| `earth-seasons` 昼夜与四季 · 保留／P1 | 自转决定昼夜，地轴倾斜连同公转改变各纬度日照角与昼长；南北半球相反，零倾角可作反证。 | 以同一地面观察者、地轴和日期联动地球球体、天空路径与昼长读数。北京／南半球、六月／十二月、0°／约 23.4° 可同屏对照；太阳高度不直接宣称当地气温。 |
| `volcano-eruption` 火山 · 保留／P1 | 岩浆补给 → 岩脉推进或停滞 → 喷发／侵入 → 不同物质堆积 → 冷却、侵蚀、生境或积水等条件分支。 | 首屏从地下前置状态开始；同一山体剖面与地表输出共用状态。先走少量代表主线，再进盾状、成层、渣锥、海底和火山湖分支；不得画成每座火山都必然成湖、长森林。 |
| `wind` 风 · 保留／P1 | 不均匀受热与压强差让空气流动；海陆风、台风和龙卷风所需条件与尺度不同；风怎样影响物体。 | 复用方向、湿度和速度的视觉编码，但每个场景有自己的尺度标尺与新增条件。条件不足时显示无组织风场或不形成的结果，不把三种风暴排成同一风速等级。 |
| `lightning-thunder` 闪电与雷 · 保留／P1 | 电荷分离 → 通道发展／回击 → 空气快速受热 → 光与声以不同速度到达。 | 把云内电荷、先导与回击放大成可回放的一次事件；观察者距离改变先看到与后听到的间隔。分叉是本次情景，不代表每道闪电都同形；慢放时间须标清。 |
| `rain-cycle` 水循环 · 保留／P1 | 同一流域的水有云、河、土壤、地下与冰的多条去向；不是每滴水走同一圈，也不在同一时间尺度上回来。 | 先用 100 份水的分叉账本观察“去哪儿”，再沿选定一份进入云滴、河道、入渗或冰川细节。切到长期地下水／冰川模型时显式切换批次与时间，避免把两套收支误认同一份水。 |
| `sand-journey` 沙粒 · 暂收起 | 岩石或生物硬结构 → 破碎、磨蚀 → 水流／海浪分选 → 海滩沉积；不是所有沙都由同一类岩石来。 | 现有颗粒轨迹和圆滑度主要按进度预设，宽画面颗粒过小。恢复独立入口前，须有可观察的材料、搬运强弱与沉积位置对照，并追踪同一颗粒的历史；也可与河流到海岸的地貌旅程实质整合。 |

## 物质与现象

| 题目与决定 | 孩子最终应串起的知识 | 主画面、操作与精良门槛 |
| --- | --- | --- |
| `rainbow` 彩虹 · 保留／P0 | 阳光在雨滴中折射、内部反射与色散；观察者、太阳和雨滴的几何关系决定看到的弧，双虹有另一条光路。 | 现有首帧近乎空白。先给雨后天空和观察者的完整构图，让孩子预测弧的位置；镜头进入同一代表雨滴看光路，再回天空。光线颜色、太阳高度和弧的位置消耗同一几何状态；箭头不冒充真实单束可见光。 |
| `buoyancy` 浮力 · 保留／P1 | 同质量的泥从球变船，能排开多少水与能否载货相关；进水后结果改变。 | 一团泥连续变形为船壳，固定四块货物前后对照；同步显示水线、排水量与船沿阈值。三种实验使用一致的水面参照，不以形状切换偷偷改变材料质量。 |

| `water-states` 水的变化 · 保留／P1 | 热量进出改变同一冰水样本和相变比例；开放杯蒸发／冷盖凝结属于另一环境。 | 保留冰、水与潜热账本，另开“开放杯—空气—冷盖”的可追踪水路。环境切换时明确重置边界与守恒范围；放大分子符号不能当可见粒子。 |

| `sound-vibrations` 声音与听觉 · 保留／P1 | 声源振动 → 空气局部扰动 → 鼓膜与耳蜗机械响应 → 神经消息；频率与振幅不是同一量。 | 以同一次拨动的脉冲前沿和事件时间连接声源、空气、耳内三站，不再像三张换页插图。耳内比例与时间夸张就地标注；音频由用户触发，并区分合成声音与真实录音。 |
| `friction` 运动与停车 · 保留／P1 | 接触导致能量转移；轮胎滚动／打滑、驾驶员反应／制动距离、乘员惯性／约束分别决定结果。 | 增强首屏接触材质和受力区域，保持地面参照点；停车图并排对齐反应段、制动段与乘员减速。车辆案例是条件实验，不把安全距离显示成适用所有道路的保证。 |
| `soap-bubbles` 肥皂泡 · 保留／P0 | 在给定体积和薄膜条件下，表面张力使泡趋圆；液膜排流改变厚度，干涉让颜色随厚度与视角变化。 | 透明泡与可选薄膜位置放在首屏；现有标题／介绍将主画面压到视口下方。局部显微图跟随同一取样点，边缘厚度、反射和排液有层次；干涉假色／强化效果就地说明。 |
