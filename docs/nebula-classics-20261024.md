# 经典星云形态与自然体积纹理 · 2026-10-24

## 观察问题

同样是气体和尘埃，为什么照片里会出现明亮空腔、长柱和暗轮廓？先找形态，再在同一份物质上比较发射、散射和遮光。三个经典参考是不同对象，选择顺序不表示演化。
