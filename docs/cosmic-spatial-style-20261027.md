# 宇宙尺度 02 / 04 的空间风格统一

日期：2026-10-27。范围只含《星系与宇宙尺度》的结构地址与连续拉远；保留已有未提交工作。仅本地精修，未提交、推送或部署。

## 观察设计

- 核心问题：太阳系、星系、群与团以及大尺度分布有哪些结构差别？同一对象怎样出现在更大的视野里？
- 可变条件：02 手动转动观察方向、切换结构；04 保留对数拉远进度、起点与倾角。
- 可观察结果：球面、星盘厚度、尘带、星系的前后排布，以及密集结点、丝状点群和相对稀疏的空洞。
- 解释顺序：01 直径比较 → 02 结构归属 → 03 星系结构 → 04 连续物理标尺，不把这些问题合成一套错误的等比例套球。
- 误解防护：统计点群不是完整星系普查；丝状分布不是发光绳索；虚线观测范围不是实体外壳。拉远中的细节切换也不表示宇宙结构正在形成。
- 依据：保留既有 NASA / ESA / Tully 等来源及取整距离；大尺度外观是教学统计构图，不能用于量取星系位置、丝状区域宽度或回溯时间。参见 [ESA 宇宙物质分布介绍](https://www.esa.int/Science_Exploration/Space_Science/Planck/Tools_to_study_the_distribution_of_matter_in_the_Universe)。

## 实施边界

02 使用一个懒加载、按需绘制的三维场景，复用专题的体积星系与新宇宙网资源；旧 Canvas 保留作资源失败时的简化视图。完整方位旋转、俯视到平视、三个角度快捷操作仍由专题拥有。布局仍不作测距，标签由实际对象投影定位，转动不会改变成员身份。场景按小缓存释放几何资源，离章及页面隐藏停止请求绘图。

04 保留原来的 km/AU/光年换算、正交相机、线性帧内投影、地球/太阳锚点、缩放版本和物理标尺。新的体积只通过同一投影放置；`macroScene.ts` 缩为标签与虚线参照。没有新增膨胀、形成或引力求解，也没有自动旋转时钟。

三种统计体积共 87,000 代表点，具有三维横截面、稀疏空洞和柔和边缘；不是连线网格、实体球壳或发光气雾。相同种子在相同视角得到相同位置。02、04 共用这一外观资源，但各自保持示意结构与物理距离的责任。

## 太阳与观察角度追加精修

太阳从均匀橙色像素噪声改为暖白光球，补上平滑颗粒与细暗沟、少量成组暗斑、临边昏暗。02 和 04 消费同一份无贴图、无时钟的材质；半径、球体与原物理标尺保持原值。细纹按屏幕分辨能力过滤，避免小太阳变成噪点；表面不是实时图像、温度图或颗粒大小标尺。依据见 [NASA/Marshall](https://solarscience.msfc.nasa.gov/surface.shtml) 与 [NSO](https://nso.edu/for-public/sun-science/photosphere/)。

旧 pitch 范围 0.46–1.16 弧度确实达不到平视。新范围 0–π/2，方位可转整圈；俯视和平视直接操作使用真正的场景旋转，不替换成另一张图。必要时相机扩大取景来容纳完整俯视轨道；平视时轨道参考线淡出，避免多条投影线横穿太阳。实际天体位置和半径不随视角变化，各地址保留自己的观察方向。
