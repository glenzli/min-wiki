Each has a working interactive study, a focused full Chinese and English manuscript, three deeper learning notes, four narration sections, text/storyboard downloads and claim-specific references. The museum overview supplies the connections rather than duplicating every full manuscript. `parentTopic` preserves direct routes without adding eight repetitive catalog cards. ## Scientific and asset checks

All nine supplied museum JPEGs were materialized into the consumer cloud environment, verified readable and actually viewed. Their topics guided planning; no original photo, visitor, copied display illustration or panel text is published. Covers are original generated editorial artwork with prompts/provenance and qualified alternative text. Programmatic scenes are explanations, not observations or scans. Existing Earth surface/cloud assets retain their Solar System Scope CC BY 4.0 attribution.

The supplied Astra checklist was applied where relevant: ICS **2026/06** period boundaries and quoted errors in deeper material; boundary ages distinct from deposit ages and durations; Earth's chosen 4540 Ma ruler distinct from a precise birthday; eukaryotes/multicellularity/animals distinct; earliest recovered evidence distinct from origins; oxygen production distinct from net accumulation; branching rather than a ladder toward humans; different extinction causes and evidence weights; birds within dinosaurs; coal formation without the absent-decomposer myth; fossil constraints, comparative inference and artistic completion distinguished. Community composites state their regional/time limits and do not guarantee every illustrated functional group coexisted in one sampled bed. Plant parts record shape constraints and invented color/pose/crown details.

The multiscale source reviews found concrete defects that were corrected by Sol: mixed 2D section coordinates, a shallow intrusion appearing before transport, a second-fault displacement hidden by endpoint-only tests, layering terminating at the wrong contact, a no-melt branch retaining a crystallization statement and two playback controllers addressing the same button. The final F2 regression inspects actual mesh vertices through intermediate depths at several geological stages, rather than only testing an analytic helper. Visual revisions replaced regular surface ripples and disconnected coarse grain spheres with stable surface detail and fitted material domains. Global terrain remains an idealized teaching geometry, not a realistic reconstruction of a particular continent.

Minerals, rocks and economic ores have independent linked studies; gem quality/use is a crossing designation. Occurrence views connect veins, geodes, pockets and grains to matrix-bearing display specimens. Lattices are not inferred from crystal silhouettes. Rocks need not contain many minerals and may include non-crystalline material. Color alone cannot identify a sample. Deep-Earth sampling is separated from seismic inference; lithosphere is not crust, the mantle is mainly solid, and iron meteorites are not core samples. GOE and glaciations are extended, uncertain histories. Day/night and auroras have different causes. Habitability controls do not invent evaporation or atmospheric-loss thresholds. Each gallery's `sources.md` records exact claims, units and limits.

## Architecture and recovery

The shared stage owns presentation, camera and lifetime only. Topic modules own science and consume the same state for readouts, diagrams and meshes. The catalog does not initialize 3D. Gallery and scene modules load on demand; only the selected scene owns a WebGL context. DPR is capped at 1.35 for narrow/coarse devices and 1.5 otherwise; geometry detail varies by device. Rendering is requested by changes, with no idle animation loop. Hidden/offscreen views pause; switching releases geometry, materials, textures, observers, controls and contexts. Async generation guards discard late imports.

Routes retain bounded namespaced state across the museum and standalone galleries, including ordinary manuscript links, language, read-only mode and reading anchors. Reader infers same-family links from existing `parentTopic` metadata, gives authored destination values priority and does not interpret Earth-specific science. Registered Markdown links now retain authored query parameters and explicit empty fragments. Static reading does not import study modules. In-browser module failures require a new document to retry because Chromium caches failed imports; recovery reloads preserve URL state.

Finite process playback uses a shared presentation clock with gallery-owned mappings and budgets. It starts paused, supports scrub/reset and stops at its endpoint. Reduced-motion playback uses discrete stages. No numerical playback duration is claimed as real geological, ecological or ice-flow time. During active playback the in-memory route retains each observation while URL and link writes are coalesced to 2 Hz; pause/end and native navigation flush the current snapshot. Figure visibility is checked both before starting and while playing.

Rift A retains the same position, geological stage, F1 event phase and P1 identities across three observation scales. Earthquake replay is independent of the geological sequence; melting is a separate branch from fault slip. Cool, sealed, stalled and unloaded controls expose contrasting outcomes, without guaranteeing eruption, ocean formation or a quake at every increment. The climate chain keeps the fixed 45°N A point and ice coverage while separating global coverage, local accumulation/ablation and sample observation clocks. Sea ice derives from seawater; upland ice derives from snowfall. The irregular edge's latitude readout belongs to A's reference meridian, not a global mean. The uniform 100-portion light budget is not a cloud- or latitude-resolved planetary climate calculation. None of these global pictures is a paleogeographic reconstruction.

## Reproduce the paired preview

Install dependencies in both sibling checkouts using Node 22.12+; this environment uses Node 24.19.0 and npm 11.9.0. From `min-wiki`:

```sh
npm ci --cache /tmp/earth-npm-cache
npm run prepare:entries
WIKI_READER_ROOT=../wiki-reader npm run check
WIKI_READER_ROOT=../wiki-reader npm run dev
```

Open `http://localhost:5175/encyclopedia/topics/earth/?lang=zh`. Use `lang=en`, any standalone ID above, or `static=1`. The package lock still pins the verified public Reader main; explicitly selecting the paired Reader branch is required for the added ordinary-link state contract. No unpublished commit is advertised as remotely installable.
