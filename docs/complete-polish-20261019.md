## 后续绘图方向的取舍

用户进一步要求逐题判断颜色、写实与卡通程度、三维/伪三维/平面表达，以及不同画法之间的转折。具体原则已补入[设计原则第 6 节](design-principles.md#6-视觉材质几何与运动共同解释对象)。下面记录采用的方向，不表示这些画面已经完成新一轮重绘或美术验收。

| 当前题材 | 绘图方向与取舍 |
| --- | --- |
| 地月、黑洞、宇宙尺度 | 空间观察保留三维几何和一致光照；直径比较使用平面的共同标尺，结构地址使用明确的示意图。天体形体保持可信，光学图与几何图分别交代表示含义。 |
| 大气、雷电、水循环 | 球面、云体和地貌具有空间与材质层次；高度剖面、粒子过程和传播关系适当平面化。外景与机制通过同一地点或标记衔接，配色围绕空气、水、地表与当前重点安排。 |
| 植物、昆虫，以及继续精修的细胞、人体 | 外观走自然科学插画方向，优先轮廓、结构、厚薄与连接；微观与局部机制采用清楚的剖面和有用途的假色。细胞与器官不依赖卡通表情，当前草稿仍按原状态保留。 |
| 水、冰、浮力、肥皂泡 | 固定外观可用伪三维表现玻璃、水面、冰体和薄膜；分子及膜剖面以平面图解释。透明度与高光服从同一几何，保持宏观标记与局部位置对应。 |
| 影子、磁铁、摩擦 | 涉及光线投影时保留三维几何；桌面物品以伪三维材质建立质感，接触与受力图保持简洁。玩具可以亲切，动作原因仍由光路、接触和力表达。 |
| 制冷、电路、飞行、听觉 | 机器外观用克制的体积与零件细节；电路、热量关系、机翼剖面与耳内机制优先清晰的平面或剖面表达。外观与内部图保留部位和方向线索，不用装饰遮挡关键连接。 |
| 程序、手机通信 | 小车可保留适度卡通感以帮助追踪角色；设备图标可有轻微体积感，指令与消息路径保持平面化。拓扑排列不制造真实距离或实景空间的暗示。 |

本次只补充绘图判断标准和题材方向，检查文档差异与本地链接；没有修改演示、稿件状态或既有构建，也没有新增部署。
