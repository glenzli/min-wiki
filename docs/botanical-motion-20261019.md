# 植物案例的分层动作精修 · 2026-10-19

## 本轮改动

樱桃案例继续使用保留节点的 SVG 插画。蜜蜂细分为胸腹、复眼、触角、六足、前后翅与花粉篮，采用低饱和琥珀、棕褐和半透明翼膜。靠近时减速并伸足停靠，收翅后再展开起飞，沿向前、向上的弧线离开。柔和的翼影表示快速运动；显示节律未经真实振翅频率校准，不用画面反推生物测量。

携带花粉的参考点保持一致：蜂体俯仰围绕该点发生，接触后花粉留在同一个柱头位置。相容性仍决定花粉管与受精能否继续，不以视觉动画覆盖科学条件。花瓣凋落加入轻微翻转；枝叶围绕原叶柄锚点摆动；菜豆真叶舒展时逐渐调整角度。所有动作读取原有有限过程进度，暂停、回放、案例切换和减少动态偏好不引入额外后台循环。

手机暗色模式验收发现提示文案被固定深灰覆盖，已改用现有主题的次要文字色。阅读器的单层边界、播放栏和按钮规范保持现有结构。
