## 这次怎样用同一个标准比较

参考的是近期火山、恒星和星系尺度中已经达到的解释能力：[设计原则](design-principles.md)规定的图形、核心解释、对照、操作路径四项必须共同成立。不是把所有专题改成纪录片，也不是给3D加分、给2D减分。

1. **能从画面理解原因和去向。** 不仅结果好看，还能看见材料从哪里来、在哪里发生变化、最后去了哪里；失败、减弱或另一种结果也必须成立。
2. **放大有实际收益。** 岩浆冷壳、云内明暗、组织连接和接触界面要解释对象。只有加粗色块、重复球体或移动发光图标不足以通过。
3. **过程和对象连得上。** 中间态、回退、切视角、材料脱离后的历史应一致，不能把忽然出现或消失当形成过程。
4. **画面主导一个问题。** 首次入口、控制与下一步明确；文字解释图，而非替粗糙或矛盾的图补结论。
5. **知道什么是示意。** 未知结构、增强颜色、时间压缩和不同标尺要有边界；精美不是实测证据。

飞机、影子、磁铁是可辨的实验对象；电路、程序、消息路径适合精细二维或拓扑图。它们不需要火山岩石式材质才能成为成品。水循环的概括流域与树木仍可改进，但当前成品依据是水的分流、储存、渗流和井的接触关系可以观察；不把它当纪录片景观的视觉标杆。冰水相变的浅色界面也可继续提高对比，不因此否定已通过的同一样本条件对照。

## 优先修订顺序

先处理会让孩子得出矛盾结论的分支：**声音**的最小非零输入被映射为耳内零输入，**开花植物**的不相容花粉末态仍出现“果核里面有种子”的插图说明。本轮分别回读 `sound-vibrations/projectModel.ts` 与 `flower-fruit/growthScene.ts`，问题仍在，不因外观精修而提档。**运动与摩擦**的儿童保护分支也应优先补同一个体的身体—座椅—安全带接触关系。

随后优先做接近成品但核心画面尚不均衡的太阳系、小天体、风、四季、彩虹与叶片；再围绕真实组织/形态精修植物、动物和人体类。电池与AI先收敛一次可完成的问题路径，避免先增加更多章节。
