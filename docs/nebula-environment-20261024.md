# 经典星云的周边环境 · 2026-10-24

用户接受上一轮创生之柱的主体外观，并要求适量补足周围环境。本轮保留主体物质场、薄亮边、
光学积分和观察控件，补充远处不均匀的云光、断续暗带与疏密、亮度不同的星点。
学习重点是辨认局部致密结构与更大星云环境的关系，周边保持低对比，不增加菜单或独立动画。

## 参考与边界

实际查看了 [ESO/DSS2 鹰状星云广视场合成照片](https://esahubble.org/images/heic1501e/)
及 [ESA/Hubble 对创生之柱的说明](https://esahubble.org/news/heic1501/)。后者把气尘柱放在较大星云环境中，
并说明附近热星的辐射、恒星风与受照边缘的关系。

广视场约为 3.8×3.3 度，与柱体近景不是同一视场。这里只借鉴弥散云光、不均匀暗带和星点分布，
没有把两张不同视场的照片按比例拼接，没有下载照片作为运行纹理，也没有采用星表坐标。
增强配色、星点位置/亮度、云光分布与距离均是教学设计，不是裸眼景象或观测三维重建。
图旁中英限定已同步说明周边环境的示意性质。

## 实现与资源

- `nebulaEnvironment.ts` 拥有固定对象坐标下的远方气尘方向场、三组配色和星点分布。
  不同经典对象采用不同环境；照明只改变显示响应，星点和物质方向场不变。
- WebGL 复用原有背景球，只增加一份当前 768×384 RGBA 权重数组/纹理和一组 760 星点。
  输入数组为 1,179,648 字节；这不是测得的 GPU 总显存。首次进入经典星云时准备，切换案例时原位填充，
  不保存多个案例的纹理。普通转动和照明切换不重建该数组，场景销毁时释放纹理和星点资源。
- 环境星点位于半径24的球上，摄像机最大距离19；在本场景的观察位置，星点处于主体后方。
  渲染次序使主体尘埃衰减背景云光与星点。明亮星点占少数，没有均匀铺满的大星芒或闪烁时钟。
- 远云是固定方向场的背景示意，主体仍是可转动体积；不把背景纹理解释为有测量深度的新体积模拟。
  行星状星云、超新星遗迹和恒星演化继续使用原来的星空背景。
- Canvas 后备路径保留一张当前 520×280 背景图，同样包含环境星点。
  每条云射线衰减这张实际背景，避免暗尘区域被另一块较亮底色覆盖。
  后备仍是低精度固定投影；不声称与 WebGL 的光学积分逐像素相同。
- 无新渲染器、工作线程、循环或后处理目标。一次 Node 字段准备诊断约529ms，
  不代表浏览器加载时间、GPU 时间或手机帧率。
