# 浮力：从水托住水，到同一份金属变成船

2026-10-23。用户批准以连续分镜重做浮力，优先讲清同形水替换与恒质量金属成船。旧实验台本地稿保存在 `/private/tmp/buoyancy-journey-20261023/before/`，本次不提交或发布。

## 设计约束

- 核心问题：周围的水怎样托住物体，排开水的重量为什么能说明托力，改变金属形状又改变了什么。
- 条件：圆木、石头、硬币、船；同一份 780 g、100 mL 金属；0–8 块各 100 g 货物；淡水/海水。讲解尺度和视角不改实验条件。货物是附加质量，金属自身质量始终不变。
- 可观察结果：入水、下沉/上浮、同形水与物体在原位替换、金属取出/压薄/围起船沿/重新入水、吃水和进水。过程可暂停与回退；同一进度得到同一状态。
- 因果：原位水体由周围水托住 → 相同水位和边界下换入物体，水的压力作用不变 → 比较物体与同形水的重量 → 金属船壳排除水的空腔扩大可用排水容积 → 漂浮或船沿进水。
- 易误解点：虚线不是水膜；水未凭空增加；沉下也有浮力；金属没有变轻；展开面积本身不保证漂浮；干舱进水后不再计入排水空腔；深处更高水压不等于分子更快/更密。
- 边界：均匀静水的浸入量与受力计算，运动路径和成形过程为可回退教学示意，不求解流体动力学、材料塑性、进水速率或倾覆。硬币、木头等单独取景，不暗示跨物体相同几何比例。金属闭合网格与排水计算共同使用同一成形轮廓，检查材料体积不变。触底仍假设水接触下表面，不求解密封接触。

## 四段连续问题

1. 岸边观察：选择一个完整物体，猜测，再放入水中；主体拥有材质、厚度、接触、运动与最终落点。
2. 水托住水：圈出一份水；说明周围水恰好托住其重量；固定水位和边界，渐变替换为相同物体；再释放观察。圆木可从完全浸没后上升；重物下沉；干船保持有效的部分浸没边界。
3. 水怎样推：同一姿态切整体压力与 A/B 接触处。微观活动只推进观察相位，物体和物理状态保留；平均表压与分子活动分开编码。
4. 金属变成船：实心下沉 → 取出 → 压薄 → 抬起船沿 → 重新入水 → 停稳。随后加货可比较吃水与进水。所有成形在水面上完成，同一网格与材质保持身份。

## 视觉和界面

自然岸边、浅水底与远处植物建立情境。水面、物体、同形水是前景；水底石粒和远处植物只建立空间。避免灰雾、乳白水膜、整齐水箱和装饰泛滥。完整物体、取出的金属及干船舱始终可辨。

主画面占主区域，控制在画外。当前一句问题、一条原因、播放/进度在视野中；直接选择三个关键中间态。每段仅显示当前有效控制，分子活动的暂停范围有明确文字。桌面与 390px 中英文实际检查。
