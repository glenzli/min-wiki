# 百科收敛：按问题与机制，而非篇幅

日期：2026-09-20。依据 [设计原则](design-principles.md)。本轮为本地实施记录，不授权提交、推送或部署。

## 判定方式

- **合并**：存在同一机制、条件门槛或有意义的前后过程；合并后可以使用共同的观察参照，说明差异，而不是只增加菜单。
- **保留**：有独立可操作问题和不同结果，即使实现短、没有三维或数值求解，也不等于没有价值。
- **收起重复独立入口**：介绍层次过薄，或关键解释已被完整主专题吸收。去掉重复目录和独立控制界面，保留有用模型、资料与旧链接。
- **暂不硬并**：只是同属“动物”“身体”“天气”等宽泛分类，没有具体问题链。先保留关联阅读，不为凑一个大专题而制造因果关系。

本轮检查了现有 49 个顶层条目的目录和源码归属，重点深入检查下面三组及若干看起来较简单的实验。此表是编辑决策，不是对全部未改专题重新完成科学和视觉验收。

## 本轮三组

| 新主入口（复用原 URL） | 吸收的独立入口 | 需要建立的理解关系 | 不能暗示的关系 |
| --- | --- | --- | --- |
| 微生物：细胞、环境与病毒 `microbes-everywhere` | `bacteria`、`viruses` | 环境与资源条件→细菌结构和生长→病毒仍依赖合适的活宿主；宿主可能阻止附着或复制 | 厚壁参考细菌不是展示 T4 类噬菌体复制的同一个宿主；空气中出现不等于正在繁殖 |
| 开花植物：从种子到下一代 `seed-sprouting` | `flower-fruit`、`seed-travel` | 条件性萌发→幼苗长大后繁殖→授粉/受精→种子与果实→传播→下一代的条件 | 菜豆、樱桃、蒲公英与牛蒡是比较案例；不能把它们拼成一株植物变换物种，落地也不自动萌发 |
| 制冷：热量怎样被搬走 `air-conditioner` | `refrigerator` | 冷端吸热、外功输入、热端放热→比较空调房间与冰箱柜体→热负荷和温控 | 两个设备的示意系数不能直接横向比较；冷媒不是空气，开门冰箱不是房间制冷器 |

将 8 个顶层入口收敛为 3 个，顶层总数从 49 变为 44。65 个既有发布路由继续构建，5 个旧入口定向到对应章节；不使用 `draft` 让兼容页面从生产构建消失。搜索旧标题和关键词仍能找到主专题，中文与英文相同。主入口的旧问题也保留为搜索词。

## 其余内容的取舍

以下按问题簇记录保留理由，不将问题簇改成新的目录父项。

| 保留条目 | 理由与边界 |
| --- | --- |
| 太阳系、恒星、黑洞、宇宙尺度 | 已有不同尺度和机制边界，不能再拼成一张巨大“宇宙”菜单 |
| 地球和月亮、月球陨石坑、流星 | 月相几何、固体表面撞击和大气入射不同；后两者可后续设计“遭遇大气与地表”对照，但本轮不硬并 |
| 大气、风、水循环、雷电、四季、火山 | 彼此关联但前提、机制与操作变量独立；保持跨题关联，不把下雨、闪电、风暴排成必然连续阶段 |
| 沙子的旅程 | 矿物/生物来源和颗粒搬运不等于水本身的循环；本轮暂留，未来需加强与原河流沉积物的身份衔接 |
| 叶片、含羞草、绣球、仙人掌 | 色素变化、运动响应、铝与花色、旱生储水各有独立条件；不以“都是植物”合并 |
| 蝴蝶、青蛙 | 都涉及发育，但阶段与器官变化不等价；适合以后做明确对照，不直接套用共同时间轴 |
| 蚂蚁路线、鱼鳃、鸭蹼、伪装 | 化学信号、气体交换、划水回程和背景对照不同。鸭蹼目前主要是单次机制演示，是后续补充可变条件的候选，而不是凭短小就删除 |
| 细胞、消化、听觉、味嗅觉、疼痛 | 组织分工与不同系统的信息/物质路径有清楚边界；不能把所有身体内容塞进“细胞” |
| 洗手、自来水、乘车约束 | 分别有去污、不同污染类别与煮沸边界、减速与身体约束的操作问题；不是无机制的生活常识卡片 |
| 影子、磁铁、摩擦力、浮力 | 已有光源几何、不同材料/极性、同初速的不同摩擦系数、排水与承载对照，内容简单但有明确实验价值 |
| 彩虹、肥皂泡、水的状态、声音振动 | 折射/色散、薄膜与表面张力、相变和振动的条件不同；声音发生可关联听觉，但不是同一阶段或同一分类中的重复介绍 |
| 电池 | 化学能、电路与马达有独立能量/载流路径，不与制冷按“都是电器”合并 |

## 实施与验收

专题团队分别拥有植物、微生物与制冷目录；主任务串行维护目录、共享英文、整合测试和源码边界。继承的其他未提交修改不回滚、不清理。保留专题科学模型的归属，不引入首页模拟器依赖或通用科学引擎。

每组交付必须验证：真实章节内容、条件分支、按案例保留暂停状态、前进/回退、快速切换、语言与旧路由、390 px、异步生命周期及模型边界。全站门禁和生产浏览器结果在完成后追加，不能用前一轮通过记录代替本轮证据。

### 实际移除的内容

五个旧入口的完整页面控制器被精确章节跳转替代；植物和制冷需要的控制逻辑移入专题内的 study 模块，微生物由统一工作区直接使用原科学渲染器。移除 `bacteria/style.css` 与 `viruses/style.css` 两份不再被使用的旧页面样式，可从 Git 恢复；原科学模型、细胞与宿主细节、细菌角色插画和封面没有删除。

本轮没有因为篇幅短而删除独立实验，也没有改动部署配置或发布远端。各项判断的可追溯记录分别在三个主专题 README 内。

### 完成时证据

- 全站 `npm run check` 的测试阶段运行 562 项，定位到唯一失败：制冷 learning 的段落数不符合统一结构。修复中英内容为 3 段学术笔记、4 段解说，保留原正文与画面提示，未放宽测试。
- 修复后 `node --import tsx --test tests/learning.test.mjs tests/consolidation.test.mjs` 为 **72/72**。其他已通过的 490 项对应源码未再改变，复用该结果；不把定向复验说成再次跑完全部测试。
- 最终 `npm run build` 通过：TypeScript、6452 条源文案 / 66 个英文命名空间、131 份图片副本一致性及 Vite 生产构建；`git diff --check` 通过。
- 构建仍提示共享 Three.js chunk 超过默认大小阈值；微生物环境插画因固定环境参照而在首屏静态使用，所以它的动态 import 不会另拆 chunk。这不是“所有资源都懒加载”或整站性能已优化的证据。
- 开发页面实际检查：植物缺水阻断、花粉不相容终态无果实、传播落地不自动萌发及章节返回；细菌资源受限停在复制前；制冷热端内外的不同收支。综合开发与生产页，三组中英页面均检查了 390 px 布局，未见横向溢出；原封面按新主入口检查并复用。
- 最终生产预览 `http://127.0.0.1:4175/` 实测了五个旧入口，分别进入 bacteria、viruses、reproduction、dispersal、fridge 对应章节；抽查语言、模型参数与 `#narration` 保留。部署子路径由纯路由测试验证，并未另启子路径服务器。
- 生产交互实测：病毒 successful/defended 案例往返仍分别保留 5 / 2 的进度；细菌中间态 0.6 跨章后浏览器回退保持；冰箱进度 450 跨房间边界章返回保持暂停，累计 294 + 147 = 441 kJ 与共同热量账一致；三份数示意没有与冰箱累计 kJ 混用。
- 生产页面检查了中英说明和学术模式、中文 390 px 图形、英文宽度及章节状态；首页显示 **44 个演示**，搜索“冰箱”只返回统一制冷入口。验收标签未记录 console error/warn，结束后恢复默认视口并关闭临时标签，保留用户原预览标签。

这些是选定条件与路径的验收，不是全部参数组合、浏览器 BFCache 资格或生物/设备预测精度的证明。异步取消、过时加载拒绝、有限时钟与镜头恢复另由实际渲染器及生命周期定向测试覆盖。最终仅更新本地工作区和生产预览，未提交、推送或部署。
