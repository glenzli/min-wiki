本轮仅为本地源码修改。上一轮未提交成果保留；提交、推送、安装插件和部署均未执行。

## 核心问题与职责

地球历史应让读者看见同一颗行星的变化，并通过现存材料理解历史知识的依据。年代、事件身份、证据与形成假说不能被一条没有限定的动画混为一谈。地球探索地图下八题继续各有独立科学所有者，历史负责时间与证据的连接。

本轮先解决截图中的外层不齐：主场景、图注、播放栏、读数各自定义留白，宽按钮与进度条又混用不同网格。Reader 提供可选的展示区域，专题保留布局、对象、参数、科学回调和时钟。新样式在独立 `/Users/g4i/lab/wiki-reader` 源仓库维护，内容通过已有 `WIKI_READER_ROOT` 开发桥消费；不修改依赖目录或安装中的插件。

| 标记 | Reader 提供 | 专题保留 |
| --- | --- | --- |
| `data-reader-workbench` | 明确采用通用区域的边界 | 是否采用、组合顺序、宽度与布局 |
| `data-reader-controls` | 通用留白与控件换行 | 观察问题、参数、切换及交互 |
| `data-reader-stage` | 通栏区域，无重复外框 | 画面大小、比例、渲染、命中几何 |
| `data-reader-transport` / `data-reader-actions` | 播放区与按钮组排版 | 开始、暂停、结束和复位的含义 |
| `data-reader-scrub` | 标签、原生滑块、读数及限定语布局 | 值、单位、有效区间、回调和可逆性 |
| `data-reader-caption` / `data-reader-legend` | 图注、图例的留白与基础排版 | 表示含义、色彩和科学限定 |
| `data-reader-readout` / `data-reader-prose` | 阅读留白与基本字距 | 内容、读数结构和深入说明 |

桌面默认 20px、手机 16px 留白，可通过变量调整。嵌套区域避免重复留白。组件不足宽度时，进度区自然转到下一行；不是依赖整页宽度猜测侧栏空间。默认规则低优先级，专题可覆盖；`data-reader-ui="custom"` 是明确的局部自定义出口。既有 `data-reader-toolbar` 仍表示目标区域 ID，没有改成另一种布局标记。Reader 不猜测未知参数，不制造播放按钮或强制固定侧栏。

## 历史的十二个代表观察站

采用既有历史模型中的形成、内部物质分配、月球、水、早期生命、氧、成冰纪、寒武纪、森林、二叠纪危机、K–Pg 与今天。旧 28 条历史线索、完整线性年代尺及独立氧收支实验继续存在，没有用十二帧替换所有历史知识。

一个三维场景拥有整球、附着的局部环境与材料证据三种观察尺度。放大的陨石、锆石、微生物席、铁层、冰碛/擦痕、化石、根系与撞击线索为原创教学几何，不是样品扫描或真实显微照片。现代地表图只在今天使用；古代轮廓、冰/雾/植被提示值不是古地理复原或测得的覆盖曲线。

有限播放由用户发起。每段先固定代表年代观察，再加速跨时；两条约 4500 Ma 的路标仍有不同身份，没有虚构两者间的地质年数。撞击与局地喷发只在对应命名事件的观察段出现，不持续穿过后续几千万年。原年代与事件是共同权威状态，视角切换不重置氧实验；新展示位置须与这些状态一致才被接受。

## 精细化与避免重叠

- 内部：采用 Reader 区域，去掉重复的按钮/进度网格和零边距说明；保留闭合地壳/岩石圈、断层和独立时钟。
- 历史：新增有条件的整球材质、局部接触与放大证据；继续检查自然轮廓、材质和真实的渲染接触。
- 古生命：重复压痕与成对刮痕更可辨，保留造迹者与行为的不确定性。
- 岩石：明确砂粒、孔隙及胶结物；加入的基质不再继承花岗岩外观。
- 矿物：晶体底部使用同一母岩表面，避免悬浮与硬切接触。
- 矿石：改进固定脉壁的不规则接触、石英颗粒和金属斑块。
- 冰川：采用同一控件、图注与阅读区域，保留积累/消融预算和示踪物身份。
- 海洋：水体正面、顶面与侧面显示同一分界，保留水团身份与状态计算。

现有深入专题继续拥有各自模型。历史不复制完整板块、群落、冰川、岩石或海洋实验。可复用的是 Reader 展示职责；科学知识与资源生命周期仍可独立演进。
