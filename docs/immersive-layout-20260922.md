# 沉浸演示与 16:9 布局检查

日期：2026-09-22。基线：`eaf3204`。本轮优化黑洞五章、星系与宇宙尺度三章的
观察工作区，并检查共享组件对浮力、水的三态、磁铁的兼容性；未宣称全站都已改造。

## 交互目标与实现

- 核心问题：画面、当前条件和播放控制能否同时看见，而不被周边阅读内容挤到下一屏。
- 可变条件：普通/沉浸、解说和设置开合、窗口宽高；科学条件与进度继续由专题控制。
- 可观察结果：画面使用剩余高度，控制保持可达；黑洞并排比较与连续拉远不再上下堆叠。
- 状态连续：不重建演示 DOM；开合解说、设置、进入/退出沉浸不重置进度。跨章仍用原专题状态。
- 易误解处：不能为“塞进屏幕”把圆压成椭圆、偷偷放大小天体，或让新取景沿用过时的物理宽度读数。
- 模型边界：仅改取景与布局。黑洞两侧使用同一比例；宇宙短画布统一扩大水平视野，读数与标尺同步。

黑洞和宇宙页均提供“沉浸演示 / Immersive view”，默认收起解说和设置，在顶部可随时
展开。Esc 恢复阅读布局、先前面板开合与滚动位置。黑洞保留沉浸内章节选择；宇宙页保留
三个观察章节。必要的比例、定位符号和几何限定仍可见或就近展开。

桌面工作区根据实际可用高度适配；长解说在独立区域阅读。手机使用较紧凑的工具条、
可读的选择框及可滚动回退，避免通过裁切使操作失去入口。没有启用浏览器原生全屏，
也没有自动播放或开启声音。
